# REQ-FR-plan.horizon.three-horizons

**Приоритет:** P0
**Ключевая функция:** F1.3
**Источник:** UC-plan.horizon.show-three-horizons; vision.md F1.3 (P: «ученик не видит, что доступно сейчас и куда идти»)
**Описание:** Маршрут отображается в виде трёх горизонтов — срезов одного вычисленного маршрута: дальний горизонт — полный маршрут до цели (все модули); средний горизонт — критический путь, 3–5 ближайших обязательных модулей; ближний горизонт — «доступно сейчас»: модули, у которых все strict-пререквизиты (`hasStrictPrerequisite`) освоены. Горизонты пересчитываются при каждом событии `RouteRecalculated` и обновляются на экране без перезагрузки. Ближний горизонт интерактивен: запуск модуля (статус «в работе»), показ ресурсов (F1.4) и историй/проектов (F5.3) как вход в шаг.

**Критерии приёмки:**
- Ближний горизонт содержит ровно те модули, у которых все strict-пререквизиты освоены: 100% модулей ближнего горизонта удовлетворяют правилу доступности, модулей с незакрытым strict-пререквизитом = 0.
- Средний горизонт содержит от 3 до 5 ближайших модулей критического пути; при остатке менее 3 обязательных модулей до цели отображается доступное количество с пометкой близости цели (допустимый размер 1–2 с пометкой, 0 пустых средних горизонтов при ненулевом маршруте).
- Дальний горизонт покрывает весь маршрут: каждый `RouteStep` вычисленного маршрута виден в дальнем горизонте (покрытие 100%, «фантомных» модулей вне маршрута = 0).
- Горизонты согласованы между собой: любой модуль среднего и ближнего горизонтов присутствует в дальнем горизонте (0 модулей, отсутствующих в полном маршруте).
- Обновление: при событии `RouteRecalculated` новые горизонты отображаются ≤ 2 с без перезагрузки страницы; при пустом ближнем горизонте показывается причина (незакрытый пререквизит) и предлагается переход к диагностике лакун (F2.1) — 0 пустых ближних горизонтов без объяснения.
- Отсутствие маршрута (цель не задана) обрабатывается явно: система предлагает постановку цели и запуск вычисления маршрута (0 ошибок интерфейса).
