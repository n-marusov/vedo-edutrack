# REQ-NFR-ui.compliance.supported-browsers

**Приоритет:** P0
**Ключевая функция:** cross-cutting (F4 — фронтенд)
**Источник:** quality-matrix audit ячейка 1.2 (Среда/Эксплуатация), vision G3; уроки опыта: ADA/WCAG-иски 2025, Canvas LMS 2026 (единая точка отказа)

**Описание:** Система должна сохранять работоспособность в определённой технологической среде эксплуатации: поддерживаемые браузеры, операционные системы и типы устройств. Требование закрывает лакуну «Среда/Эксплуатация» матрицы программирования качества (ячейка 1.2) — функции системы (F4.1–F4.7) должны работать на заявленных платформах.

**Критерии приёмки:**
- Поддержка браузеров: последние 2 мажорные версии Chrome, Firefox, Safari, Edge (на момент релиза).
- Поддержка ОС: Windows 10+, macOS 12+, iOS 15+, Android 11+.
- Основные сценарии (построение маршрута, карта знаний, дашборды) выполняются без деградации на всех поддерживаемых браузерах — проверяется кросс-браузерным тест-сьютом перед каждым релизом.
- Минимальная скорость сети: интерактивность карты знаний сохраняется при 1 Мбит/с (проверяется профилем сетевого throttling).
- Отсутствие поддержки браузера сообщается пользователю с инструкцией по обновлению (не блокируя остальной функционал).
