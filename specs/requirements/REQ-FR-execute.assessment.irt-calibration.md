# REQ-FR-execute.assessment.irt-calibration

**Приоритет:** P1
**Ключевая функция:** F2.2
**Источник:** vision.md F2.2
**Описание:** Калибровка проверочных заданий по трудности на общей латентной шкале (модели IRT/Раша): каждому заданию присваивается параметр трудности; для новых заданий трудность оценивается по априорной модели и уточняется по ответам учеников (онлайн-калибровка). Оценка освоения ученика вычисляется как латентная переменная (уровень способности) по ответам с указанием погрешности измерения (standard error, SE). Контроль качества: конструктная валидность (измеряется именно освоение модуля) и надёжность (внутренняя согласованность набора заданий). Откалиброванные задания и оценки с погрешностью являются входом для позиции ученика, прогноза (F2.5) и диагностики лакун (F2.1).
**Критерии приёмки:**
- Каждое задание имеет параметр трудности на общей латентной шкале (логиты IRT/Раша); для заданий с ≥30 ответами трудность откалибрована (апостериорная оценка), для остальных — априорная с пометкой «не калибровано» (A2 UC).
- Оценка освоения публикуется с погрешностью измерения: SE ≤ 0.3 логита при наборе ≥8 заданий; значение SE указывается в каждой записи `Mastery`.
- Калибровка пересчитывается при накоплении новых ответов (онлайн-калибровка): обновление параметров не реже 1 раза в сутки или при накоплении ≥50 новых ответов на задание.
- Надёжность набора: внутренняя согласованность (α Кронбаха или эквивалент IRT) ≥ 0.7; при меньшем значении набор дополняется заданиями или результат помечается «низкая точность» (A4 UC).
- Конструктная валидность: задания, не измеряющие освоение целевого модуля, отклоняются на этапе валидации (F2.2); отклонения логируются с указанием причины.
- Откалиброванные оценки (уровень + SE) используются позицией, прогнозом (F2.5) и диагностикой лакун (F2.1): порог освоения применяется с учётом погрешности.
