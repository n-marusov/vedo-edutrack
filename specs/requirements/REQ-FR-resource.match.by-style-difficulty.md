# REQ-FR-resource.match.by-style-difficulty

**Приоритет:** P2
**Ключевая функция:** F3.2
**Источник:** UC-resource.match.match-resources-to-learner (исключён из MVP — этап 2)
**Описание:** Система подбирает ресурсы под обучающегося по стилю обучения, уровню сложности, длительности и бюджету (например, «видео до 20 минут»). Подбор использует фиксированную таксономию стилей обучения и жёсткие ограничения по длительности и стоимости. Требование реализуется на этапе 2 и не входит в MVP.
**Критерии приёмки:**
- Таксономия стилей обучения — закрытое множество {visual, auditory, kinesthetic, reading/writing}; подбор использует только значения из этой таксономии, неизвестные значения игнорируются с предупреждением.
- Ресурсы с длительностью больше установленного лимита пользователя (например, video > 20 мин при ограничении «видео до 20 минут») исключаются из выдачи — детерминированный фильтр.
- Ресурсы со стоимостью, превышающей остаток бюджета пользователя, исключаются из выдачи.
- Точность подбора: в топ-10 рекомендаций ≥ 90% ресурсов соответствуют стилю обучения пользователя и уровню сложности ±1.
- Если ни один ресурс не удовлетворяет всем ограничениям, система возвращает ближайшие по критериям ресурсы с явным перечнем нарушенных ограничений.
