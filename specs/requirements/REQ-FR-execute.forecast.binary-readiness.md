# REQ-FR-execute.forecast.binary-readiness

**Приоритет:** P0
**Ключевая функция:** F2.5
**Источник:** UC-execute.forecast.binary-readiness-forecast; vision.md F2.5
**Описание:** Система строит прогноз выполнения плана к контрольной точке на основе текущего темпа ученика, оставшихся модулей плана и известных дефицитов (F2.1). В MVP — бинарный прогноз: «успевает» (on-track) / «не успевает» (not-on-track): оценка времени на оставшиеся модули при текущем темпе сравнивается с временем, доступным до контрольной точки (с учётом буфера). Прогноз пересчитывается при событии `PlanDeviationDetected`, при освоении модуля (`module.mastered`), на периодической основе (ежедневно/еженедельно) и при приближении контрольной точки. Результат: статус, ожидаемая дата завершения, остаток времени, ключевые риски. На этапе 2 — трёхуровневый прогноз «успевает / под риском (отклонение в пределах допуска, < 15%) / не успевает» с точностью ±10%. При вердикте not-on-track запускаются уведомление (F2.6) и рекомендации: дополнительные часы, приоритизация закрытия дефицитов, предложение пересмотра плана (F1.9).
**Критерии приёмки:**
- Точность бинарного прогноза: на ретроспективной выборке ≥100 завершённых планов доля верных вердиктов (on-track/not-on-track) ≥85% (доля ошибок <15%).
- Прогноз пересчитывается при каждом событии `PlanDeviationDetected` и `module.mastered`; обновлённый вердикт доступен в GUI/API ≤5 с после события.
- Результат прогноза содержит: статус (on-track/not-on-track), ожидаемую дату завершения, остаток времени до контрольной точки, перечень ключевых рисков (дефициты F2.1, отставания F2.4).
- При вердикте not-on-track система запускает уведомление (F2.6) и формирует рекомендации: дополнительные часы, приоритизация закрытия дефицитов, предложение пересмотра плана (F1.9).
- На этапе 2: вердикт «под риском» выставляется при отклонении в пределах допуска (<15%); точность трёхуровневого прогноза ±10% на выборке ≥100 планов.
- При недостатке данных о темпе прогноз использует дефолтный темп контекста и помечается «низкая точность» (A3 UC).
