# REQ-FR-api.hub.copy-subgraph

**Приоритет:** P0
**Ключевая функция:** F0.2
**Источник:** vision.md F0.2, F1.1.1 (построение графа достижимости); REQ-FR-plan.compute.shortest-path

**Описание:** Сервис должен копировать релевантный подграф онтологии (модули, достижимые из текущей позиции ученика, с их связями и атрибутами) в память EduTrack для вычислений маршрутов и планов. Копия используется движком маршрутов (не на стороне Hub); полнота и консистентность копии гарантированы. Требование закрывает лакуну F0.2 FR-слоя.

**Критерии приёмки:**
- Подграф включает 100% модулей, достижимых из заданной позиции ученика (по strict/soft-связям), с их атрибутами и связями.
- Консистентность копии: 0 связей, ссылающихся на отсутствующие в копии узлы (проверка автоматическим тестом целостности).
- Время копирования подграфа ≤ 5 секунд для онтологии до 10 000 модулей на эталонном окружении.
- Копия версионируется вместе с версией онтологии (согласуется с REQ-FR-api.hub.read-ontology и REQ-FR-plan.compute.shortest-path); при обновлении онтологии подграф перекопируется инкрементально.
- Копирование не блокирует пользовательский поток: выполняется асинхронно с таймаутом ≤ 3 с на запрос к Hub (см. REQ-NFR-api.availability.hub-dependency-sla).
