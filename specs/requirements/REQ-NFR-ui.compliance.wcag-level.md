# REQ-NFR-ui.compliance.wcag-level

**Приоритет:** P0
**Ключевая функция:** cross-cutting (UI)
**Источник:** README.md (требования), vision.md (a11y), WCAG 2.1 AA, quality-matrix.md (2.2, ADA/WCAG-иски 2025)

**Описание:** Весь пользовательский интерфейс соответствует WCAG 2.1 уровня AA; перед каждым релизом выполняется автоматический a11y-аудит (axe-core) с требованием 0 критических нарушений (critical violations); нарушение gate блокирует релиз.

**Критерии приёмки:**
- Уровень соответствия: все страницы и интерактивные компоненты удовлетворяют критериям успеха WCAG 2.1 уровня AA (контраст текста ≥ 4.5:1, полноценная навигация с клавиатуры, альтернативный текст, корректная ARIA-разметка).
- Автоматический аудит-гейт: в CI перед каждым релизом запускается axe-core на всех маршрутах приложения (viewport desktop + mobile ≥ 320px); результат — 0 critical и 0 serious нарушений; любое critical/serious нарушение → fail сборки (релиз заблокирован).
- Покрытие аудитом: a11y-сканом покрыто ≥ 90% страниц/экранов приложения; история результатов аудитов хранится — количество нарушений не растёт между релизами (регрессия = 0 ухудшений).
- Ручная проверка ключевых сценариев (навигация с клавиатуры, скринридер NVDA/JAWS) выполняется для новых фич перед релизом; чек-лист из ≥ 10 пунктов (порядок фокуса, лейблы полей, структура заголовков, skip-link, видимый фокус) пройден на 100%.
