# REQ-FR-plan.resource.match-to-step

**Приоритет:** P1
**Ключевая функция:** F1.4
**Источник:** UC-plan.resource.match-resources-to-steps; vision.md F1.4, F3.2 (P: «непонятно, на каких материалах проходить модуль»)
**Описание:** Для каждого шага маршрута система подбирает все доступные ресурсы: контент-ресурсы (видео, статьи, интерактивы, учебники, книги) и ресурсы обеспечения (репетиторы/наставники, оборудование, доступы) с фильтром по профилю ученика — стиль обучения, формат, сложность, длительность, бюджет (F3.2). Подбор выполняется при событии `RouteRecalculated` (каскад F1.6), при фиксации плана (`PlanFixed`) и при изменении профиля ученика. Доступность ресурсов обеспечения проверяется (F3.3): недоступные помечаются, предлагаются альтернативы (дороже/быстрее, дешевле/дольше); затраты по маршруту пересчитываются и сверяются с бюджетом (F3.4).

**Критерии приёмки:**
- Корректность фильтра: 100% возвращённых для шага ресурсов удовлетворяют всем заданным жёстким критериям профиля (формат, стиль, сложность, длительность, бюджет) — нарушений фильтра = 0.
- Полнота подбора: доля шагов маршрута с ≥ 1 подобранным ресурсом при наличии подходящих ресурсов в онтологии ≥ 95%; при отсутствии ресурсов под фильтр система снимает необязательные критерии и помечает шаг «ресурсы не подобраны» (шагов с пустым результатом без пометки = 0).
- Доступность: каждый подобранный ресурс обеспечения (репетитор, оборудование, доступ) имеет подтверждённую доступность на даты шага, либо шаг содержит ≥ 1 альтернативу с указанием разницы по времени/цене — 100% шагов проверены.
- Бюджет: суммарная стоимость ресурсов маршрута пересчитывается при каждом подборе и сверяется с бюджетом; при превышении бюджета предлагаются более дешёвые альтернативы (0 подборок, превышающих бюджет без альтернатив).
- Актуальность: подборка соответствует текущей версии маршрута — устаревшие привязки ресурсов к модулям, отсутствующим в маршруте, удаляются при пересчёте (0 устаревших привязок в публикуемой подборке).
