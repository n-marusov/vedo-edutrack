# REQ-FR-onboarding.landing.explore-value-proposition

**Приоритет:** P1
**Ключевая функция:** cross-cutting (публичная витрина продукта)
**Источник:** UC-onboarding.landing.explore-value-proposition, vision.md §2.5 (фронтенд — общее демо возможностей сервиса), G3 (снизить порог входа), roadmap M0.3 (landing page)

**Описание:** Публичная посадочная страница (`/`), доступная без авторизации, сообщает ценностное предложение VEDO EduTrack: персональная образовательная траектория на основе графа знаний, отслеживание прогресса (план-факт) и диагностика пробелов. Страница содержит hero-секцию с названием и слоганом, три карточки ценностных предложений, CTA-кнопки «Sign In» (→ `/login`) и «Learn More» (якорь к секции возможностей), футер. Страница маршрутизирует посетителя к входу/регистрации (M0.3) и поддерживает локали RU + EN (i18n-ready).

**Критерии приёмки:**
- Страница доступна без авторизации по корневому URL `/`: сервер возвращает SPA с HTTP 200; аутентификация не требуется.
- Hero-секция содержит название «VEDO EduTrack» и слоган «Персональная образовательная траектория на основе графа знаний» (или английский эквивалент).
- На странице присутствуют 3 карточки ценностных предложений: Knowledge Graph Routes (персональные маршруты), Progress Tracking (план-факт), Gap Diagnosis (диагностика пробелов); отсутствие любой из карточек считается дефектом.
- CTA «Sign In» ведёт на `/login`; CTA «Learn More» прокручивает страницу к секции возможностей (якорь) — проверяется автоматическим тестом маршрутизации/навигации.
- Футер содержит копирайт и ссылки.
- Страница отображается на русском и английском языках без изменения кода (только файлы переводов) — согласуется с REQ-NFR-ops.compliance.i18n-readiness; недостающие переводы показываются на русском (fallback).
- Авторизованный пользователь при переходе на `/` перенаправляется на ролевой дашборд (`/dashboard`).
- Доступность: автоматический a11y-аудит (axe-core) на странице показывает 0 critical- и 0 serious-нарушений (согласуется с REQ-NFR-ui.compliance.wcag-level).
