# REQ-FR-execute.alert.deviation

**Приоритет:** P1
**Ключевая функция:** F2.6
**Источник:** UC-execute.alert.deviation-alert; vision.md F2.6 (P18)
**Описание:** При отставании от плана более чем на N дней система формирует и доставляет уведомление родителю / HR / ученику: «Отставание на N дней по модулю X. Рекомендация: …». Уведомление запускается событием `PlanDeviationDetected` (F2.4) при превышении порога N; порог настраивается по контексту/аккаунту (родитель, школа, HR). Содержимое: модуль, величина отставания в днях, плановая и фактическая даты, причина отклонения (F2.4), прогноз последствий (F2.5) и рекомендация (дополнительные часы, доосвоение корневой лакуны F2.1, перераспределение нагрузки). Доставка выполняется по каналу аккаунта (email, push, мессенджер); наружу публикуется событие `plan.deviated` (webhook). Доставка логируется; при недоступности канала — повтор по расписанию с эскалацией на резервный канал; при повторном превышении порога по тому же модулю — эскалация с усиленной рекомендацией и предложением пересмотра плана (F1.9).
**Критерии приёмки:**
- Порог N дней конфигурируется отдельно для каждого контекста/аккаунта (родитель, школа, HR); изменение порога применяется без перезапуска сервиса (≤1 мин) и вступает в силу для следующих проверок.
- Уведомление отправляется тогда и только тогда, когда отставание по модулю > N дней: проверка на ≥10 сценариях (в пределах порога — доставки нет, за порогом — доставка есть).
- Тело каждого уведомления содержит все обязательные поля: модуль, отставание в днях, плановую и фактическую даты, причину, прогноз последствий, рекомендацию; полнота проверяется автоматическим тестом на 100% сгенерированных уведомлений.
- Доставка выполняется по каналу аккаунта; при недоступности канала — до 3 повторов по расписанию и эскалация на резервный канал; каждый факт доставки/недоставки логируется с отметкой времени.
- При каждом уведомлении наружу публикуется событие `plan.deviated` (webhook); при отказе аккаунта от уведомлений данного типа событие фиксируется в журнале, доставка пропускается (A4 UC).
- При повторном превышении порога по тому же модулю (ухудшение отставания) отправляется эскалация с усиленной рекомендацией и предложением пересмотра плана (F1.9).
