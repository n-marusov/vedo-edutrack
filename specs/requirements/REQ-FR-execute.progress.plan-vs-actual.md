# REQ-FR-execute.progress.plan-vs-actual

**Приоритет:** P0
**Ключевая функция:** F2.4
**Источник:** UC-execute.progress.plan-vs-actual-comparison; vision.md F2.4
**Описание:** Для каждого модуля зафиксированного плана (снэпшот F1.8) система сопоставляет плановую дату завершения с фактической датой освоения, вычисляет отклонение в днях (положительное — опоздание, отрицательное — ускорение) и фиксирует причину отклонения: ускорение / требовалось больше практики / перерыв / изменение объёма. Сверка план-факт запускается периодически (ежедневно/еженедельно), при событии `module.mastered` и при наступлении плановой даты шага. При выходе отклонения за допуск (±15% по срокам или порог в днях) публикуется событие `PlanDeviationDetected`, запускающее каскад: пересмотр прогноза (F2.5), уведомления (F2.6), при провале контрольной точки — предложение пересмотра плана (F1.9). Отчёт «план и факт» обновляется и доступен в GUI/API.
**Критерии приёмки:**
- Для 100% модулей зафиксированного плана вычислено отклонение в днях (фактическая дата освоения − плановая дата завершения); результаты совпадают с эталонным расчётом на тестовом наборе ≥20 модулей (расхождение 0 дней).
- Для каждого модуля с отклонением ≠ 0 зафиксирована причина из набора {ускорение, требовалось больше практики, перерыв, изменение объёма, не указана}; доля модулей с причиной «не указана» ≤5%.
- Событие `PlanDeviationDetected` публикуется тогда и только тогда, когда отклонение превышает допуск плана (проверка на ≥5 сценариях в пределах и за пределами допуска).
- Отчёт «план и факт» содержит для каждого шага: плановую дату, фактическую дату, отклонение в днях, причину, статус (запланирован → доступен → в работе → освоен → подтверждён); обновляется при событии `module.mastered` и не реже 1 раза в сутки.
- Модуль, освоенный вне зафиксированного плана, не включается в сверку, но фиксируется в траектории и помечается расхождением маршрута и плана (A1 UC).
- При отсутствии зафиксированного плана сверка недоступна: система показывает только фактическую траекторию без отклонений (A2 UC).
