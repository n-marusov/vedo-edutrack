# REQ-FR-api.integration.lms-connectors

**Приоритет:** P1
**Ключевая функция:** F6.3
**Источник:** vision.md F6.3, 1.7, 3.2 (критический фактор «Интеграции с LMS»); roadmap M6 (этап 2); REQ-FR-api.rest.compute-route

**Описание:** Сервис должен предоставлять готовые коннекторы к LMS (WebTutor, iSpring, SAP SuccessFactors) для двустороннего обмена: маршрут передаётся в LMS как учебный план, прогресс и оценки возвращаются из LMS. Требование этапа 2 (M6); из коробки LMS-коннекторы исключены из MVP (vision 2.5 — «Интеграции с LMS из коробки: MVP: API»). Требование закрывает лакуну F6.3 FR-слоя.

**Критерии приёмки:**
- Коннекторы для 3 LMS: WebTutor, iSpring, SAP SuccessFactors; каждый коннектор реализует двусторонний обмен (маршрут → план в LMS; прогресс/оценки ← из LMS).
- Двусторонняя синхронизация: событие освоения модуля в LMS передаётся в EduTrack и обновляет позицию ученика (согласуется с REQ-FR-execute.progress.plan-vs-actual и webhooks); задержка синхронизации ≤ 15 минут.
- Идемпотентность: повторная синхронизация одного события не создаёт дубликатов (0 дубликатов — согласуется с REQ-FR-api.webhooks.idempotency).
- Обработка ошибок LMS: недоступность LMS не блокирует работу EduTrack (маршруты считаются по кэшу); ошибки LMS логируются и повторяются по расписанию (DLQ, см. REQ-FR-api.webhooks.module-mastered).
- Конфигурация: каждый коннектор настраивается через конфигурацию (URL, credentials, маппинг ролей) без изменения кода ядра (модель кастомизации vision 1.7).
