# REQ-NFR-api.availability.hub-dependency-sla

**Приоритет:** P0
**Ключевая функция:** F0 (порт онтологии)
**Источник:** quality-matrix audit ячейка 1.2 (Среда — SLA смежных систем), vision 1.7, 3.2; урок опыта: Canvas LMS 2026 — недоступность вендора парализовала обучение

**Описание:** EduTrack — сервис-слой поверх VEDO Hub: маршруты и покрытие зависят от доступности Hub API. Требование фиксирует SLA на зависимость и режим деградации (офлайн-кэш релевантного подграфа) — чтобы недоступность Hub не останавливала критические функции (карта знаний, план-факт, покрытие ФГОС).

**Критерии приёмки:**
- Документированный SLA: целевая доступность VEDO Hub API ≥ 99.5% (контракт с платформой).
- Режим деградации: при недоступности Hub сервис продолжает обслуживать чтение последнего скопированного подграфа (офлайн-кэш) не менее 24 часов без потери данных прогресса.
- Таймауты: запросы к Hub API имеют таймаут ≤ 3 с и не блокируют пользовательский поток (асинхронная обработка, circuit breaker).
- Метрика: доля запросов к Hub, завершённых без ошибки при доступном Hub, ≥ 99.5% за месяц.
- Повторная синхронизация подграфа выполняется автоматически после восстановления Hub (инкрементально, с верификацией версии онтологии).
