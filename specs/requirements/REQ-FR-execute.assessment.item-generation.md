# REQ-FR-execute.assessment.item-generation

**Приоритет:** P1
**Ключевая функция:** F2.2
**Источник:** UC-execute.assessment.assessment-item-generation; vision.md F2.2
**Описание:** Генерация проверочных заданий под конкретный модуль и уровень освоения по паттерну Generate-and-Validate: LLM-модуль генерирует набор кандидатов заданий (вопросы, задачи, действия), детерминированное ядро валидирует их — соответствие содержанию модуля, отсутствие двусмысленностей, корректность ответов, содержательная валидность (покрытие модуля). Для проверки собирается набор заданий разной трудности (серия индикаторов, а не одно задание) с контролем надёжности (внутренняя согласованность) и валидности (конструктной — измеряется именно освоение модуля). По ответам ученика система оценивает освоение с погрешностью и фиксирует запись `Mastery` (уровень + погрешность). Результат используется позицией (событие `module.mastered` при достижении порога), прогнозом (F2.5) и диагностикой лакун (F2.1). Фолбэк при недоступности LLM-провайдера — банк проверенных заданий ядра.
**Критерии приёмки:**
- Для каждого модуля и уровня освоения система формирует набор из ≥5 валидных заданий; на тестовой выборке из 100 сгенерированных наборов доля наборов с дефектным заданием (несоответствие модулю, ошибка ответа, двусмысленность) = 0%.
- Содержательная валидность: каждое ключевое умение/тема модуля (по онтологии) покрыта ≥1 заданием в наборе; доля покрытых умений ≥95% на выборке ≥20 модулей.
- При отклонении ядром >30% LLM-кандидатов генерация повторяется с уточнённым контекстом или используется банк проверенных заданий (A1 UC); факт отклонения логируется.
- Оценка освоения по ответам сопровождается погрешностью: каждая запись `Mastery` содержит уровень и погрешность измерения.
- При результате ниже порога освоения (с учётом погрешности) модуль не считается освоенным, фиксируется частичное освоение и запускается диагностика лакун (F2.1) (A3 UC).
- При недоступности LLM-провайдера генерация использует банк проверенных заданий ядра; результат помечается соответствующей уверенностью (A5 UC).
