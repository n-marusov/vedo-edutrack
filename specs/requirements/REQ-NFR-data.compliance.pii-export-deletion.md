# REQ-NFR-data.compliance.pii-export-deletion

**Приоритет:** P1
**Ключевая функция:** cross-cutting (данные пользователей)
**Источник:** quality-matrix audit ячейки 1.4/2.4/3.4/4.4 (Вывод из эксплуатации), vision 2.9 (Community/Enterprise), 152-ФЗ (право на удаление ПДн)

**Описание:** Требование закрывает лакуны колонки «Вывод из эксплуатации / Миграция» матрицы программирования качества: пользователь должен иметь возможность экспортировать свои данные и инициировать удаление аккаунта с полным удалением персональных данных (право на забвение), а система — корректно завершать жизненный цикл данных.

**Критерии приёмки:**
- Экспорт данных пользователя в машиночитаемом формате (JSON/CSV): прогресс, маршруты, планы, освоения, история событий — доступен в личном кабинете.
- Срок подготовки экспорта: ≤ 30 минут для аккаунта с любым объёмом данных; уведомление о готовности ссылки на скачивание.
- Удаление аккаунта: инициируется пользователем, подтверждается, завершается полным удалением ПДн из всех хранилищ (основных и резервных копий) ≤ 30 дней.
- Аудит-след удаления: запись о факте удаления и его полноте сохраняется без ПДн (анонимизированная метадата).
- Enterprise-контур: удаление ПДн по 152-ФЗ выполняется по запросу субъекта данных с подтверждением полноты удаления.
- При недоступности удаления (зависшие транзакции) система сообщает пользователю статус и повторяет операцию до успеха.
