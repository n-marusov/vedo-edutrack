# REQ-NFR-ops.ergonomics.admin-console

**Приоритет:** P1
**Ключевая функция:** cross-cutting (операции/эргономика)
**Источник:** quality-matrix audit ячейка 2.3 (Эргономика/Сопровождение — консоли администратора), развитие REQ-NFR-ops.observability.golden-signals-dashboards и REQ-NFR-ops.observability.alerting-escalation; практика: ошибки операторов при неэргономичных консолях → инциденты

**Описание:** Консоли администрирования обязаны соответствовать эргономическим требованиям: скорость выполнения частых операций, понятность статусов, защита от ошибочных деструктивных действий — чтобы операторы работали быстро и без ошибок. Требование углубляет ячейку 2.3 (Эргономика/Сопровождение) с 🟡 до 🟢.

**Критерии приёмки:**
- Скорость частых операций: типовые операции администратора (просмотр статуса, поиск записи, сброс пароля) выполняются ≤ 30 секунд (p95); измеряется юзабилити-тестом с ≥ 3 операторами.
- Статусы: консоль отображает статус всех систем/сервисов одним экраном (согласуется с REQ-NFR-ops.observability.golden-signals-dashboards); время до полной картины ≤ 5 секунд.
- Защита от ошибок: деструктивные действия (удаление, массовое изменение) требуют подтверждения (двойной ввод/подтверждающий диалог); 100% деструктивных операций защищены.
- Понятность: консоль на языке UI (русский), термины соответствуют глоссарию проекта; 100% действий имеют понятные подписи.
- Согласуется с REQ-NFR-ops.access.production-control (2-person rule) и REQ-NFR-ops.observability.alerting-escalation (эргономика алертов).
