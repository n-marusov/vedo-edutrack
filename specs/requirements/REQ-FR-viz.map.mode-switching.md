# REQ-FR-viz.map.mode-switching

**Приоритет:** P0
**Ключевая функция:** F4.1
**Источник:** UC-viz.map.view-knowledge-graph-with-progress, vision.md F4.1
**Описание:** Карта знаний поддерживает два режима просмотра с переключением в один клик: (1) критический путь (critical path) — отображаются только essential- и strict-связи и узлы, входящие в них; (2) режим исследования (exploration) — отображается полный граф со всеми типами связей: enriches, appliesTo, stories, project ideas. Переключение не сбрасывает прогресс и текущее положение обучающегося на карте.
**Критерии приёмки:**
- В режиме critical path на карте присутствуют только узлы и рёбра типов essential и strict; на тестовом графе, где есть рёбра всех четырёх типов, в critical path отсутствуют рёбра enriches, appliesTo, stories, project ideas — 100% исключение.
- В режиме exploration отображаются все узлы и рёбра полного графа (essential, strict, enriches, appliesTo, stories, project ideas); количество отрисованных рёбер совпадает с количеством рёбер в источнике данных.
- Переключение между режимами выполняется одним кликом по переключателю режимов; задержка отображения нового режима не превышает 500 мс на графе до 500 узлов.
- Текущий активный режим явно индицируется в интерфейсе.
- Прогресс, цветовая кодировка статусов и каскадные стрелки сохраняются при переключении режимов.
