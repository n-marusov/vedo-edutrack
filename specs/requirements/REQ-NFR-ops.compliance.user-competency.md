# REQ-NFR-ops.compliance.user-competency

**Приоритет:** P1
**Ключевая функция:** cross-cutting (компетенции пользователя)
**Источник:** quality-matrix audit ячейка 5.2 (Тех.обеспеченность/Эксплуатация — компетенции и обучение пользователей), vision.md 3.1 (разные уровни подготовки: родитель без подготовки, методист, HR); развитие REQ-NFR-ops.compliance.user-documentation

**Описание:** Пользователи обязаны иметь обучение и документацию для эксплуатации, а система — документированные требования к клиентской инфраструктуре, поскольку vision 3.1 фиксирует разные уровни подготовки пользователей (родитель без методической подготовки — критический фактор). Требование углубляет ячейку 5.2 (Тех.обеспеченность/Эксплуатация) с 🟡 до 🟢.

**Критерии приёмки:**
- Обучение: ролевые обучающие материалы (родитель, ученик, методист, HR) покрывают 100% ролей из vision 3.1; для Enterprise — обязательный онбординг-тренинг перед передачей в эксплуатацию.
- Клиентская инфраструктура: документированные требования к клиентским устройствам и сети (согласуется с REQ-NFR-ui.compliance.supported-browsers: браузеры, ОС, ≥ 1 Мбит/с); проверка совместимости при первом входе с понятным сообщением.
- Документация для эксплуатации: инструкции по частым операциям (построение маршрута, экспорт, отчёт) доступны из интерфейса ≤ 2 кликов (согласуется с REQ-NFR-ops.compliance.user-documentation).
- Эффективность обучения: доля пользователей, успешно выполнивших целевое действие после обучения (онбординг/тренинг), ≥ 80%.
- Согласуется с REQ-NFR-ops.compliance.support-sla (поддержка) и REQ-NFR-ops.compliance.user-documentation (документация).
