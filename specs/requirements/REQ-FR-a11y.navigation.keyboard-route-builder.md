# REQ-FR-a11y.navigation.keyboard-route-builder

**Приоритет:** P1
**Ключевая функция:** cross-cutting (WCAG 2.1 AA)
**Источник:** UC-a11y.navigation.keyboard-route-builder

**Описание:** Конструктор траекторий (route builder) должен быть полностью управляемым с клавиатуры: все интерактивные элементы (drag-and-drop модулей, выбор целей, настройка ограничений, кнопки) доступны и активируются с клавиатуры, фокус видим на каждом элементе, отсутствуют keyboard traps, и пользователь может выйти из любого компонента (Esc / Shift+Tab), следуя логичному порядку фокуса.

**Критерии приёмки:**
- Каждое интерактивное действие конструктора (перемещение модуля, выбор цели, изменение ограничений, сохранение траектории) выполнимо только с клавиатуры (Tab, стрелки, Enter, Space, Esc) без использования мыши — соответствие WCAG 2.1.1 (Keyboard).
- Отсутствуют keyboard traps: фокус можно свободно вывести из любого элемента или виджета сочетанием Esc или Shift+Tab, порядок фокуса логичен и не прерывается — соответствие WCAG 2.1.2 (No Keyboard Trap).
- Все focusable-элементы имеют видимый индикатор фокуса с контрастом не менее 3:1 относительно фона — соответствие WCAG 2.4.7 (Focus Visible); проверяется программно (bounding box и вычисленный стиль outline).
- Автоматизированная проверка axe-core на странице конструктора (эталонный браузер, прогон по всем сценариям построения траектории) показывает 0 critical-нарушений, включая правила keyboard/focus.
