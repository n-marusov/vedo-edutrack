# REQ-FR-resource.budget.alternative-scenarios

**Приоритет:** P2
**Ключевая функция:** F3.4
**Источник:** vision F3.4
**Описание:** Система формирует альтернативные бюджетные сценарии маршрута с компромиссом «бюджет против времени»: например, сценарий в пределах бюджета с увеличенной длительностью и ускоренный сценарий с превышением бюджета. Сценарии сравниваются по стоимости, длительности и отличию от базового маршрута. Требование реализуется на этапе 2.
**Критерии приёмки:**
- Для каждого маршрута система формирует ≥ 2 альтернативных сценария (при возможности): (a) в пределах бюджета с увеличенной длительностью, (b) ускоренный с превышением бюджета.
- Каждый сценарий содержит численные значения: общая стоимость, длительность, разница по стоимости и времени относительно базового маршрута.
- Генерация сценариев детерминирована: одинаковые входные данные дают одинаковый набор сценариев (два запуска — 100% совпадение).
- Если существует хотя бы один сценарий в пределах бюджета пользователя, система гарантированно включает его в набор.
- Сравнительная таблица сценариев отображает стоимость, длительность и отклонения от базового маршрута для 100% сгенерированных сценариев.
