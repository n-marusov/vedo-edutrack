# REQ-FR-viz.map.progress-colors

**Приоритет:** P0
**Ключевая функция:** F4.1
**Источник:** UC-viz.map.view-knowledge-graph-with-progress, vision.md F4.1
**Описание:** Интерактивная карта знаний отображает каждый модуль (узел) с цветовой индикацией статуса освоения обучающегося. Маппинг «статус → цвет» фиксирован: освоено (mastered) = зелёный, в процессе (in-progress) = жёлтый, доступно (available) = синий, заблокировано (blocked) = серый, незакрытые предусловия (unclosed prereq) = красный. Красные узлы дополнительно показывают каскадные стрелки (cascade arrows) к узлам, которые они блокируют.
**Критерии приёмки:**
- Каждый узел карты имеет ровно один из пяти статусов, и цвет узла в точности соответствует маппингу: mastered=green, in-progress=yellow, available=blue, blocked=grey, unclosed-prereq=red; на тестовом графе с 20+ узлами всех пяти статусов расхождений цвета не обнаружено.
- Узел получает статус unclosed-prereq (красный) только при наличии хотя бы одного незакрытого prerequisite-узла; при закрытии последнего prerequisite узел немедленно перекрашивается в следующий корректный статус.
- Для каждого красного узла отрисовываются каскадные стрелки ко всем непосредственно заблокированным зависимым узлам; число стрелок на тестовом графе совпадает с числом рёбер «незакрытый prereq → зависимый узел» с точностью до 100%.
- Легенда цветов отображается на карте и совпадает с маппингом из vision F4.1.
- Перерисовка карты после обновления прогресса занимает не более 1 секунды на графе до 500 узлов.
