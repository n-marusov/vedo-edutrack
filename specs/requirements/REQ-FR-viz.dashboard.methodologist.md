# REQ-FR-viz.dashboard.methodologist

**Приоритет:** P1
**Ключевая функция:** F4.5
**Источник:** UC-viz.dashboard.methodologist-dashboard, vision.md проблема P18
**Описание:** Дашборд методиста и школы отображает покрытие ФГОС по классам и по школе в целом, групповую аналитику с выделением топ-отстающих тем (top lag topics) и вклад в онтологию (ontology contribution). Агрегации вычисляются по данным всех обучающихся выбранной группы; построение отчёта выполняется быстро, чтобы методист мог работать с ним интерактивно.
**Критерии приёмки:**
- Покрытие ФГОС агрегируется по классу и по школе: значение равно доле элементов ФГОС, охваченных планами/прогрессом обучающихся группы; результат совпадает с эталонным расчётом на тестовой выборке (2 класса, 40+ обучающихся) с точностью до 1 п.п.
- Топ отстающих тем формируется по числу обучающихся с неосвоенным модулем/пробелом по теме; список отсортирован по убыванию и корректен на тестовых данных.
- Виджет вклада в онтологию отображает число добавленных/изменённых элементов онтологии за выбранный период, совпадающее с данными аудит-лога.
- Время построения/обновления отчёта для школы до 500 обучающихся не превышает 1 секунды.
- Ролевая модель: методист видит только данные своей школы/классов, к которым у него есть доступ.
