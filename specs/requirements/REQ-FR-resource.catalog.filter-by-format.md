# REQ-FR-resource.catalog.filter-by-format

**Приоритет:** P1
**Ключевая функция:** F3.2
**Источник:** UC-resource.catalog.filter-by-format (P17)
**Описание:** Пользователь может фильтровать каталог ресурсов по формату (video, text, interactive, textbook) и по источнику (source). Фильтрация применяется к текущему результату просмотра каталога и сочетается с пагинацией. При отсутствии результатов система возвращает явное состояние «ничего не найдено» с предложением сбросить фильтры.
**Критерии приёмки:**
- Фильтр по формату возвращает ровно те ресурсы, у которых format совпадает с выбранным значением: точность и полнота выборки 100% (детерминированное сравнение с полным каталогом).
- Комбинированный фильтр format + source возвращает только ресурсы, удовлетворяющие обоим условиям одновременно.
- При пустом результате система показывает состояние «ничего не найдено» с кнопкой сброса фильтров, а не ошибку или пустую страницу.
- Время ответа фильтрации ≤ 200 мс на каталоге до 10 000 ресурсов.
- Пагинация сохраняется при активных фильтрах: число элементов на странице фиксировано (например, 20), а сумма элементов по всем страницам равна общему числу отфильтрованных ресурсов.
