# REQ-FR-plan.constraint.fgos-filter

**Приоритет:** P0
**Ключевая функция:** F1.12
**Источник:** vision.md F1.12, F1.1 (приоритет модуля — модули, закрывающие ФГОС-дефициты)
**Описание:** Требования формальной рамки используются как фильтр при вычислении маршрута: в контексте «школьное образование» модули, закрывающие ФГОС-дефициты (требования рамки, не закрытые освоенными модулями), получают повышенный приоритет за N недель до аттестации — они поднимаются в критическом пути и в среднем горизонте. Значение N — настраиваемый параметр контекста обучения (конфигурация); буст применяется к ближайшей контрольной точке-аттестации. Буст не нарушает порядок разрешения конфликтов приоритетов (essential + strict → soft → enrich).

**Критерии приёмки:**
- Тайминг буста: повышенный приоритет применяется только в интервале (дата аттестации − N недель; дата аттестации] — для контрольного набора из ≥20 сценариев с датами 0 применений буста вне интервала и 100% применений внутри интервала.
- Эффект приоритета: за N недель до аттестации доля модулей, закрывающих ≥ 1 незакрытый ФГОС-дефицит, в среднем горизонте ≥ 80% (от числа ещё не освоенных закрывающих дефициты модулей), против ≤ 50% без буста для того же набора входных данных (замер на контрольном наборе из ≥20 сценариев).
- Покрытие дефицитов: в маршрутах, вычисленных за N недель до аттестации, к дате аттестации закрыто ≥ 90% ранее незакрытых требований рамки, достижимых при плановой нагрузке (0 дефицитов, пропущенных при наличии достаточного времени).
- Ненарушение конфликтов: модуль с бустом не вытесняет модуль с флагом essential+strict — порядок essential + strict → soft → enrich сохраняется (0 нарушений в тестовом наборе из ≥50 конфликтов).
- Настраиваемость N: изменение параметра N меняет момент начала буста по формуле «дата аттестации − N недель» — проверка для N ∈ {2, 4, 8} даёт 100% совпадение с формулой.
- Контекстная применимость: в контекстах, отличных от «школьное образование», ФГОС-буст не применяется (0 применений буста вне контекста школьного образования).
