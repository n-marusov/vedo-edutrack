# REQ-FR-execute.coverage.fgos-live

**Приоритет:** P0
**Ключевая функция:** F2.7
**Источник:** UC-execute.coverage.fgos-coverage-live; vision.md F2.7 (P3, P14)
**Описание:** Расчёт покрытия формальной рамки (ФГОС) в реальном времени для контекста обучения: `coverage = число требований, закрытых освоенными модулями с привязкой / общее число требований рамки`. Модуль закрывает требование, если привязан к нему в онтологии («модуль → требование»). Покрытие вычисляется на актуальной позиции ученика (множество освоенных модулей с уровнями) и пересчитывается при каждом изменении позиции (событие `module.mastered`), при обновлении рамки/привязок в онтологии и периодически перед контрольной точкой. Результат: доля закрытых требований, группировка по доменам (предметам/разделам рамки), список дефицитов (F2.7); фиксируются версии рамки и онтологии. Покрытие доступно в GUI (прогресс-бар по доменам) и API; используется прогнозом (F2.5), аттестационной готовностью (F2.8) и построением маршрута (F1.12).
**Критерии приёмки:**
- Значение coverage совпадает с эталонным расчётом по формуле на тестовом наборе ≥10 контекстов (расхождение 0).
- Освоенный модуль без привязки к требованиям рамки не увеличивает числитель покрытия (покрытие не завышается); такие модули фиксируются в аудите (A2 UC).
- Покрытие обновляется автоматически при событии `module.mastered` и при изменении привязок в онтологии: обновлённое значение доступно в GUI и API ≤5 с после события, без запроса пользователя.
- Результат содержит: долю закрытых требований, группировку по доменам и версии рамки/онтологии, использованные при расчёте.
- Модуль с уровнем освоения ниже порога (с учётом погрешности F2.2) не учитывается как освоенный для покрытия (A4 UC).
- При отсутствии рамки для контекста покрытие не вычисляется: API возвращает «нет данных», аттестационные отчёты (F2.8) недоступны (A1 UC).
