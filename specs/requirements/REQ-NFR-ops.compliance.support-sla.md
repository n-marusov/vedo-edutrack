# REQ-NFR-ops.compliance.support-sla

**Приоритет:** P2
**Ключевая функция:** cross-cutting (поддержка пользователей)
**Источник:** quality-matrix audit ячейки 5.2/1.3 (Тех.обеспеченность/Эксплуатация), vision.md §2.9 (модель монетизации: Community/Pro/Enterprise)

**Описание:** Поддержка пользователей организована по тирам в соответствии с моделью монетизации: каналы и SLA первого ответа для Community, Pro, Enterprise; публичная документация с автоматической проверкой полноты покрытия API. Требование закрывает неучтённый аспект «компетенции и инфраструктура пользователя» ячейки 5.2.

**Критерии приёмки:**
- SLA первого ответа по тирам:
  - Community: база знаний + сообщество, ответ ≤ 48 часов (тикет).
  - Pro: тикеты + мессенджер, ответ ≤ 4 часов (рабочее время).
  - Enterprise: 24/7, ответ ≤ 1 часа, выделенный менеджер.
- Покрытие документацией: ≥ 90% публичных эндпоинтов имеют описание и пример в OpenAPI (проверка автоматическая в CI).
- Changelog публикуется при каждом релизе: 100% релизов сопровождаются changelog.
- Доступность публичной документации 24/7: ≥ 99.5%.
