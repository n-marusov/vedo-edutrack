# REQ-FR-api.rest.query-coverage

**Приоритет:** P1
**Ключевая функция:** F6.1
**Источник:** UC-api.rest.query-coverage

**Описание:** Сервис должен предоставлять REST API endpoint `GET /fgos/coverage/{learner_id}` для запроса покрытия ФГОС конкретного обучающегося. Сервис сопоставляет освоенные и запланированные модули траектории с требованиями ФГОС (компетенции, индикаторы, дисциплины), вычисляет процент покрытия по каждому требованию и по стандарту в целом, а также возвращает дефициты — требования, не покрытые текущей траекторией. Расчёт выполняется на основе актуальной версии графа знаний VEDO Hub.

**Критерии приёмки:**
- `GET /fgos/coverage/{learner_id}` возвращает `200 OK` с JSON-схемой `FgosCoverage` (поля `learner_id`, `coverage_percent` (0–100), `requirements[]` с полями `requirement_id`, `status` (`covered|partial|missing`), `covered_modules[]`, `missing_modules[]`).
- Для обучающегося, траектория которого покрывает все требования стандарта, `coverage_percent` равен 100; требования со статусом `partial` или `missing` перечислены в `missing_modules[]` с указанием недостающих модулей.
- При отсутствии данных о learner возвращается `404 Not Found`; при недоступности или неактуальной версии онтологии ФГОС — `503 Service Unavailable`.
- Расчёт детерминирован: повторный запрос при неизменных данных прогресса и онтологии возвращает идентичные `coverage_percent` и состав `requirements[]`.
