# REQ-FR-viz.map.gap-diagnostic-view

**Приоритет:** P0
**Ключевая функция:** F4.6
**Источник:** UC-viz.map.view-gap-diagnostic-map, vision.md проблема P16
**Описание:** Карта диагностики пробелов (gap map) отображает только корневые разрывы (root gaps) — узлы, не освоенные обучающимся и не имеющие незакрытых prerequisites — выделенные красным, вместе с каскадными блокирующими стрелками (cascade blocking arrows) ко всем зависимым узлам. Корневые разрывы ранжируются по влиянию каскада (числу заблокированных зависимых узлов), что позволяет выбрать приоритет для устранения.
**Критерии приёмки:**
- На карте диагностики отображаются только корневые разрывы: узел показывается красным тогда и только тогда, когда он не освоен и все его prerequisites освоены либо отсутствуют; производные (некорневые) разрывы скрыты из основного вида.
- Для каждого корневого разрыва отрисовываются каскадные блокирующие стрелки ко всем зависимым узлам по цепочке prerequisites; на тестовом графе количество стрелок совпадает с расчётным значением обхода зависимостей.
- Список/список-карта корневых разрывов отсортирован по убыванию влияния каскада (число заблокированных узлов); корректность ранжирования проверяется на графе с заранее известными значениями влияния.
- Ранжирование и фильтрация пересчитываются при изменении прогресса обучающегося не более чем за 1 секунду.
