# REQ-NFR-security.compliance.pii-152-fz

**Приоритет:** P0
**Ключевая функция:** cross-cutting (Enterprise-контур)
**Источник:** vision.md (P11), DESCRIPTION.md NFR, 152-ФЗ (оборотные штрафы 2025)

**Описание:** Персональные данные (PII) в Enterprise-контуре защищаются в соответствии с 152-ФЗ: шифрование at-rest и in-transit (TLS ≥ 1.2), уведомление Роскомнадзора об инциденте — ≤ 24 часов с момента детекции, отчёт по расследованию инцидента — ≤ 72 часов.

**Критерии приёмки:**
- Тест шифрования at-rest: PII в БД и в бэкапах хранится в зашифрованном виде (AES-256 или эквивалент); чтение файлов БД/бэкапов без ключей не даёт доступа к открытому тексту PII (проверка на тестовой копии — поиск известных значений PII в сырых файлах даёт 0 совпадений).
- Тест in-transit: все эндпоинты Enterprise-контура принимают только TLS ≥ 1.2 (TLS 1.0/1.1 отключены); сканирование протоколов (например, nmap/sslscan) показывает 0 поддерживаемых устаревших версий TLS.
- Уведомление об инциденте: в drill-тесте (симуляция утечки PII) уведомление Роскомнадзора отправляется ≤ 24 часов с момента детекции; фактическое время фиксируется в отчёте.
- Отчёт по расследованию: полный отчёт (объём и категории данных, причины, mitigated actions) готов ≤ 72 часов после детекции; шаблон отчёта существует и используется в drill-тесте ≥ 1 раза в квартал; расхождений с требованиями 152-ФЗ по срокам = 0.
