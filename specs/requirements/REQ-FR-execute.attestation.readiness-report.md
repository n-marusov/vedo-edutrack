# REQ-FR-execute.attestation.readiness-report

**Приоритет:** P1
**Ключевая функция:** F2.8
**Источник:** UC-execute.attestation.attestation-readiness-report; vision.md F2.8 (P3, P6, P18)
**Описание:** Сводный отчёт об аттестационной готовности перед контрольной точкой (аттестацией): вердикт готовности (готов / под риском / не готов), покрытие по доменам (F2.7), дефициты с приоритетом (F2.7), критический путь закрытия (цепочка обязательных шагов, включая модули, закрывающие дефициты, определяющая минимальный срок достижения целевого покрытия), прогноз времени до контрольной точки (F2.5), ключевые рекомендации (что освоить в первую очередь, дополнительные часы). Генерируется по событию приближения контрольной точки или по запросу родителя/школы. Публикуется событие `AttestationReadinessReportGenerated`; отчёт сохраняется в истории; при вердикте «под риском / не готов» запускаются уведомление (F2.6) и предложение пересмотра плана (F1.9).
**Критерии приёмки:**
- Время генерации отчёта для одного ученика ≤1 с; для сводки по школе (до 80 учеников) ≤5 с.
- Отчёт содержит все обязательные разделы: покрытие по доменам, список дефицитов с приоритетом, критический путь закрытия, прогноз времени, вердикт готовности, ключевые рекомендации; полнота проверяется автоматическим тестом на 100% отчётов.
- Покрытие по доменам и список дефицитов в отчёте совпадают с актуальными значениями F2.7 на момент генерации (расхождение 0).
- Вердикт «готов» выставляется только при отсутствии незакрытых требований, обязательных для аттестации (покрытие по доменам аттестации = 100% или отсутствие критических дефицитов по правилам контекста).
- Критический путь закрытия рассчитан как минимальная по времени цепочка обязательных шагов до целевого покрытия; расчёт совпадает с эталонным на тестовом наборе ≥5 сценариев.
- При каждой генерации публикуется событие `AttestationReadinessReportGenerated`; отчёт сохраняется в истории и доступен родителю/школе.
- При вердикте «под риском / не готов» запускаются уведомление (F2.6) и предложение пересмотра плана (F1.9).
