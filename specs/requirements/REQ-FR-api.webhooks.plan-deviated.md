# REQ-FR-api.webhooks.plan-deviated

**Приоритет:** P1
**Ключевая функция:** F6.4
**Источник:** UC-api.webhooks.plan-deviated

**Описание:** Сервис должен доставлять webhook-событие `plan.deviated` подписанным внешним системам при отклонении обучающегося от учебного плана сверх заданного порога (отставание/опережение по срокам или пропуск обязательных модулей). Событие содержит запланированные и фактические показатели прогресса. Порог отклонения должен быть конфигурируемым и отражаться в payload события.

**Критерии приёмки:**
- Событие `plan.deviated` генерируется при превышении конфигурируемого порога: по умолчанию отставание от плана более чем на 20% по срокам или пропуск более 3 обязательных модулей подряд; порог изменяем через настройку и значение порога включается в payload.
- Payload соответствует схеме `PlanDeviatedEvent`: `event_id` (UUID v4), `event_type=plan.deviated`, `learner_id`, `plan_id`, `deviation_type` (`behind_schedule|skipped_modules`), `deviation_value`, `threshold`, `planned_progress_percent`, `actual_progress_percent`, `detected_at` (ISO 8601).
- Событие публикуется не позднее 15 минут после фиксации отклонения в системе прогресса и доставляется всем подписчикам с гарантией at-least-once: минимум 5 повторных попыток с экспоненциальной задержкой (1, 2, 4, 8, 16 минут), затем DLQ с алертом.
- Один эпизод отклонения эмитит одно событие: при неизменном фактическом прогрессе повторная генерация исключается (дедупликация по паре `learner_id + plan_id + deviation_type` с привязкой к `detected_at`).
