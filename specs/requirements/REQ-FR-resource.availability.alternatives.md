# REQ-FR-resource.availability.alternatives

**Приоритет:** P1
**Ключевая функция:** F3.3
**Источник:** UC-resource.availability.check-availability-and-alternatives
**Описание:** Для каждого недоступного ресурса система предлагает альтернативы: более дорогой, но быстрый вариант (more expensive/faster) либо более дешёвый, но медленный (cheaper/slower). Альтернатива сопровождается сравнением по стоимости и времени (trade-off).
**Критерии приёмки:**
- Для каждого недоступного ресурса система предлагает ≥ 1 альтернативу, если она существует в каталоге; при отсутствии альтернатив выводится явное сообщение «альтернативы не найдены».
- Каждая альтернатива помечена как more expensive/faster или cheaper/slower и содержит численные значения delta cost и delta time относительно исходного ресурса.
- Генерация альтернатив детерминирована: одинаковый вход даёт одинаковый список альтернатив (два запуска на одних данных — 100% совпадение).
- Отображение trade-off включает оба параметра (стоимость и время) для 100% предложенных альтернатив.
- Альтернатива, одновременно более дорогая и более медленная, чем исходный ресурс, исключается при генерации.
