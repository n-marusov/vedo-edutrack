# REQ-NFR-data.compliance.pii-processor-registry

**Приоритет:** P1
**Ключевая функция:** cross-cutting (данные/Enterprise)
**Источник:** quality-matrix audit ячейки 1.4/4.4 (Вывод из эксплуатации), 152-ФЗ (ст. 6, 9), GDPR processor model

**Описание:** Ведётся реестр процессоров (обработчиков) персональных данных: хостинг, CDN, аналитика, поддержка, платёжные сервисы, VEDO Hub. Каждый процессор работает на основании поручения на обработку ПДн (DPA); удаление ПДн у процессоров подтверждается отчётом.

**Критерии приёмки:**
- Реестр процессоров ПДн ведётся и актуален: 100% внешних сервисов, обрабатывающих ПДн, внесены в реестр (инвентаризация ≥ 1 раза в год, расхождений = 0).
- Для каждого процессора заключено поручение на обработку ПДн (DPA) с условиями обработки и удаления: 100% процессоров имеют DPA.
- Удаление ПДн у каждого процессора выполняется по запросу субъекта и подтверждается отчётом о полноте удаления ≤ 30 дней (согласовано с REQ-NFR-data.compliance.pii-export-deletion).
- Реестр операций с ПДн (категории данных, места хранения, процессоры) поддерживается в актуальном состоянии: сверка с фактической архитектурой = 0 расхождений.
