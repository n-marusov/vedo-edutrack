# REQ-FR-api.sparql.read-only

**Приоритет:** P1
**Ключевая функция:** F6.2
**Источник:** UC-api.sparql.read-only

**Описание:** Сервис должен предоставлять read-only SPARQL endpoint для программного доступа к графу знаний VEDO Hub: получение доступных модулей, поиск кратчайшего пути между концепциями, определение дефицитов знаний и выборка ресурсов по теме. Endpoint поддерживает только read-only формы запросов (SELECT, ASK, DESCRIBE), требует аутентификацию и применяет rate limiting и таймаут выполнения для защиты графа от перегрузки.

**Критерии приёмки:**
- Endpoint принимает запросы с Content-Type `application/sparql-query` и возвращает результаты SELECT в форматах JSON и XML; любые мутирующие операции (INSERT DATA, DELETE, LOAD, CLEAR, CREATE) отклоняются с `403 Forbidden` и сообщением о read-only режиме (проверяется автоматическими тестами по каждому типу мутации).
- Запрос без валидного API-ключа/token возвращает `401 Unauthorized`; превышение rate limit 100 запросов в минуту на одного клиента возвращает `429 Too Many Requests` с заголовком `Retry-After`.
- Запрос, выполняющийся дольше 30 секунд, прерывается и возвращает ошибку `504 Gateway Timeout`; результат, превышающий 10 000 строк, обрезается с флагом `truncated=true` в ответе.
- Запросы типа SELECT/ASK/DESCRIBE не изменяют состояние графа: контрольная выборка данных (число триплетов по тестовому графу) идентична до и после серии из 50 запросов.
