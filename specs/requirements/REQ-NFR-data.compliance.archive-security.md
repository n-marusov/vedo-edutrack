# REQ-NFR-data.compliance.archive-security

**Приоритет:** P1
**Ключевая функция:** cross-cutting (данные/вывод из эксплуатации)
**Источник:** quality-matrix audit ячейка 4.4 (Аварии/Вывод из эксплуатации — несанкционированный доступ к архивным данным), развитие REQ-NFR-data.compliance.decommissioning-safety; практика: несанкционированный доступ к архивным данным после остановки сервиса

**Описание:** Архивные данные при выводе из эксплуатации обязаны быть защищены: шифрование, контроль доступа, аудит обращений, автоматическое удаление по истечении срока хранения — чтобы предотвратить несанкционированный доступ к архивам после остановки сервиса. Требование закрывает неучтённый аспект «защита архивов» ячейки 4.4.

**Критерии приёмки:**
- Шифрование архивов: все архивные данные (логи, выгрузки, бэкапы) хранятся в зашифрованном виде (AES-256 или эквивалент); чтение архивов без ключей = 0 доступов (тест на копии — поиск известных значений ПДн в сырых файлах = 0 совпадений).
- Контроль доступа к архивам: доступ к архивным данным — только по 2-person rule (см. REQ-NFR-ops.access.production-control); 100% обращений к архивам аудируются.
- Сроки хранения: соответствуют REQ-NFR-data.compliance.retention-policy; по истечении срока — автоматическое удаление (0 данных старше срока retention).
- Аудит обращений: журнал обращений к архивам хранится без ПДн (анонимизированный); 0 неавторизованных обращений (тест).
- Архивные данные не доступны из публичных эндпоинтов после остановки сервиса: 0 открытых путей (проверка сетевым сканом).
