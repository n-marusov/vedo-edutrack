# REQ-NFR-api.performance.latency-p95

**Приоритет:** P0
**Ключевая функция:** cross-cutting (API-слой)
**Источник:** vision.md (G2), DESCRIPTION.md NFR

**Описание:** API-слой платформы VEDO EduTrack должен обеспечивать предсказуемую латентность под нагрузкой: p95 latency ответа API ≤ 200 мс при 1000 одновременных запросов; интерактивный пересчёт образовательной траектории (SPARQL-запрос к VEDO Hub) — не более 1 секунды.

**Критерии приёмки:**
- Нагрузочный тест: 1000 concurrent requests в течение ≥ 5 минут — p50 ≤ 100 мс, p95 ≤ 200 мс, p99 ≤ 500 мс; доля успешных ответов (2xx) ≥ 99%, ошибок 5xx = 0 при штатной нагрузке.
- Пересчёт траектории (SPARQL via Hub): p95 времени выполнения < 1 с на выборке из ≥ 100 пересчётов; замер включает полное время ответа VEDO Hub (не только серверное время приложения).
- Метрики p50/p95/p99 публикуются в мониторинг (Prometheus) для каждого эндпоинта; при превышении p95 > 200 мс в двух последовательных окнах измерения (≥ 5 минут) — автоматическая алерт-нотификация.
- Нагрузочный тест повторяется при каждом значимом изменении API (до merge в main) и фиксируется в отчёте с результатами p50/p95/p99.
