# REQ-FR-resource.budget.compare-with-budget

**Приоритет:** P1
**Ключевая функция:** F3.4
**Источник:** UC-resource.budget.estimate-route-budget
**Описание:** Система сравнивает оценённую стоимость маршрута с бюджетом пользователя и показывает экономику маршрута: «во сколько и с чем» — итоговую сумму, разницу с бюджетом и разбивку по типам ресурсов. При превышении бюджета выводится предупреждение о перерасходе.
**Критерии приёмки:**
- Сравнение дихотомическое: estimate ≤ budget → статус «в пределах бюджета», иначе — «превышение бюджета»; статус определяется детерминированно.
- При превышении бюджета система показывает предупреждение с абсолютной разницей |estimate − budget| и процентом перерасхода (округление до 1 знака).
- Экономика маршрута включает разбивку по типам ресурсов (content / enabling) и по шагам для 100% маршрутов.
- Все суммы отображаются в одной валюте с точностью до 2 знаков.
- Сравнение пересчитывается при каждом изменении маршрута или бюджета; задержка обновления результата ≤ 1 с.
