# REQ-NFR-ops.compliance.user-documentation

**Приоритет:** P1
**Ключевая функция:** cross-cutting (пользовательский опыт/компетенции)
**Источник:** quality-matrix audit ячейка 5.2 (Тех.обеспеченность/Эксплуатация — компетенции пользователя), vision.md 3.1 (критический фактор «Простота для родителя»), vision 1.4 (критерий успеха G1/G2 «без чтения документации»)

**Описание:** Система обязана иметь пользовательскую документацию, встроенный онбординг и обучающие материалы, поскольку vision 3.1 фиксирует «простота для родителя» как критический фактор, а критерий успеха G1/G2 требует построения маршрута «без чтения документации». Документация и обучение — необходимая составляющая компетенций пользователя для эксплуатации (ячейка 5.2).

**Критерии приёмки:**
- Встроенный онбординг: новый пользователь строит первый маршрут ≤ 5 минут от входа (согласуется с G3); проверяется юзабилити-тестом с ≥ 5 новыми пользователями перед каждым релизом.
- Пользовательская документация: справочные статьи покрывают 100% пользовательских сценариев доменов F1–F5 (маршрут, план-факт, лакуны, ФГОС, ресурсы); поиск по документации возвращает результат ≤ 2 секунд.
- Гейт обновления: 100% релизов, изменяющих пользовательский интерфейс/функциональность, сопровождаются обновлением документации (проверка в CI — ссылка на обновлённый раздел обязательна в PR).
- Обучающие материалы (статьи/видео) покрывают 100% ролей из vision 3.1: родитель, ученик, методист, HR/директор школы.
- Документация доступна на русском языке (language.ui) с техническими терминами на английском (конвенция проекта).
