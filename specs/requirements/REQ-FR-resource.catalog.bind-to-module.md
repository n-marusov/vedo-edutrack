# REQ-FR-resource.catalog.bind-to-module

**Приоритет:** P0
**Ключевая функция:** F3.1
**Источник:** vision F3.1 (MVP: базовый каталог ресурсов), quality-matrix: домен resource требует P0
**Описание:** Система поддерживает привязку ресурсов двух типов к учебным модулям: контентные ресурсы (video, text, interactive, textbook, book) и обеспечивающие ресурсы (tutors/mentors, lab equipment, access passes к музеям и лабораториям, money). Каждая привязка описывается полным набором атрибутов: тип ресурса, формат, стиль обучения, стоимость и source URL. Привязка является обязательным условием включения ресурса в маршрут обучения.
**Критерии приёмки:**
- 100% записей привязки ресурсов содержат все обязательные поля: type, format, style, cost, source URL — запись без хотя бы одного поля отклоняется системой с ошибкой валидации.
- Поле type принимает только значения {content, enabling}; любое другое значение отклоняется (дихотомическая валидация).
- Если type = content, формат ограничен множеством {video, text, interactive, textbook, book}; если type = enabling — множеством {tutor/mentor, lab equipment, access pass, money}; недопустимая комбинация отклоняется.
- Каждая привязка ссылается на существующий module ID — контроль целостности ссылок, 0 записей-сирот.
- cost — неотрицательное число с точностью до 2 знаков; source URL валиден (scheme http/https); нарушение любого из условий отклоняется при сохранении.
