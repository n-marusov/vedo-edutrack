# REQ-FR-api.mcp.server

**Приоритет:** P2
**Ключевая функция:** F6.6
**Источник:** vision.md F6.6 (stage 2)

**Описание:** На этапе 2 сервис должен предоставлять MCP-сервер (Model Context Protocol) для AI-агентов: семантический поиск по онтологии, навигация по графу знаний и извлечение контекста модулей. MCP-сервер публикует набор read-only инструментов, которые агенты вызывают для получения данных онтологии и построения образовательных рекомендаций, без возможности изменения данных VEDO Hub.

**Критерии приёмки:**
- MCP-сервер публикует не менее трёх инструментов с описаниями в формате MCP tool definitions: `search_ontology(query)`, `navigate_graph(node_id, depth)`, `get_module_context(module_id)`; каждый инструмент возвращает структурированный JSON-ответ с полями результата.
- Все инструменты read-only: попытки мутации данных через инструменты или произвольный SPARQL-запрос через MCP отклоняются с ошибкой и не изменяют онтологию (подтверждается тестом, сравнивающим состояние графа до и после вызовов).
- Инструменты требуют аутентификацию (API key/token) и ограничены rate limit 100 вызовов в минуту на одного агента; превышение возвращает ошибку `rate_limited`, запрос без токена — ошибку аутентификации.
- MCP-сервер доступен по stdio и по SSE/HTTP transport; конфигурация (endpoint, список инструментов) документирована в документации; вызов `search_ontology("Математический анализ")` возвращает релевантные концепции и модули из графа с полем `confidence`.
