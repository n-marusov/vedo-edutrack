# REQ-FR-a11y.navigation.dashboards-keyboard

**Приоритет:** P1
**Ключевая функция:** cross-cutting (WCAG 2.1 AA)
**Источник:** vision.md F4 (a11y)

**Описание:** Все дашборды системы — дашборд обучающегося, родителя/HR, методолога и панель группы — должны быть доступны с клавиатуры и для screen reader на уровне WCAG 2.1 AA: полная клавиатурная навигация, видимый фокус, корректная семантика и ARIA-атрибуты, а также текстовые альтернативы для всех не-текстовых элементов (графики, диаграммы прогресса).

**Критерии приёмки:**
- На каждом из 4 дашбордов эталонные сценарии (просмотр прогресса, фильтрация списков, открытие отчёта, экспорт) выполняются только с клавиатуры без мыши: 100% успешное прохождение сценария «открыть дашборд → получить ключевые данные → экспортировать».
- Все интерактивные элементы дашбордов имеют видимый фокус и корректные ARIA name/role/state; автоматизированный аудит axe-core на каждом дашборде показывает 0 critical- и 0 serious-нарушений.
- Диаграммы и графики прогресса имеют текстовые альтернативы (таблица или суммарные данные), объявляемые screen reader — соответствие WCAG 1.1.1; структура заголовков и landmark-регионов корректна — соответствие WCAG 1.3.1.
- Ручное тестирование NVDA/VoiceOver по эталонной матрице (4 дашборда × 3 сценария) не выявляет блокирующих дефектов доступности: каждый сценарий завершается успешно без мыши и визуального контроля, что подтверждает соответствие WCAG 2.1 AA.
