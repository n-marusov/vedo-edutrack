# REQ-FR-execute.coverage.deficit-list

**Приоритет:** P1
**Ключевая функция:** F2.7
**Источник:** UC-execute.coverage.deficit-list-with-priority; vision.md F2.7
**Описание:** Формирование списка дефицитов — незакрытых требований формальной рамки (ФГОС) — с приоритетом: (1) жёсткий пререквизит для других тем (требование, блокирующее другие требования/модули через strict-связи) > (2) часть ядра (essential-ядро контекста) > (3) опциональное (остальные). Внутри групп учитывается каскадное влияние (число зависимых требований и модулей) и близость к контрольной точке: за N недель до аттестации приоритет дефицитов, закрывающих требования аттестации, повышается (F1.12). Для каждого дефицита указываются: приоритет, статус (не закрыто / закрыто частично), связанные модули, оценка усилий, рекомендация (какие модули освоить, связь с корневыми лакунами F2.1, оценка времени F1.5). Список доступен в GUI (сортировка по приоритету, фильтры по доменам) и через API; используется аттестационной готовностью (F2.8) и построением маршрута.
**Критерии приёмки:**
- Полнота: объединение списка дефицитов и множества закрытых требований равно полному множеству требований рамки для контекста (проверка на тестовом наборе ≥10 контекстов).
- Сортировка строго по приоритету: жёсткий пререквизит > ядро > опциональное; внутри группы — по убыванию каскадного влияния; порядок совпадает с эталонным расчётом.
- Для каждого дефицита указаны: приоритет, статус (не закрыто / закрыто частично), связанные модули, оценка усилий; полнота полей проверяется на 100% записей.
- За N недель до аттестации приоритет дефицитов, закрывающих требования аттестации, повышается: позиция таких дефицитов в отсортированном списке смещается вверх (проверка на сценарии с приближением контрольной точки).
- Требование, закрытое частично (освоены не все связанные модули), помечается «частично» и включается в список с промежуточным приоритетом (A3 UC).
- Дефицит, связанные модули которого не входят в маршрут ученика, помечается «требует расширения маршрута» и передаётся в пересмотр плана (F1.9) (A4 UC).
