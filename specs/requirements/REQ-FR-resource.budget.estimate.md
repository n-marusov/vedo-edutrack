# REQ-FR-resource.budget.estimate

**Приоритет:** P1
**Ключевая функция:** F3.4
**Источник:** UC-resource.budget.estimate-route-budget (P20)
**Описание:** Система оценивает стоимость маршрута как сумму стоимостей всех ресурсов, привязанных к шагам маршрута. Оценка показывает разбивку по шагам и по типам ресурсов. В MVP используется одна валюта; при смешанных валютах применяется фиксированная таблица курсов, объявленная в конфигурации, с округлением до 2 знаков.
**Критерии приёмки:**
- Оценка стоимости маршрута = сумма стоимостей всех привязанных ресурсов; совпадает с ручным расчётом на тестовых маршрутах (N ≥ 10, совпадение 100%).
- Разбивка стоимости по шагам и по типам ресурсов (content / enabling) формируется для 100% маршрутов.
- Округление до 2 знаков; сумма элементов разбивки равна итоговой оценке (баланс 0,00 в пределах точности округления).
- При смешанных валютах конвертация выполняется по фиксированной таблице курсов из конфигурации; результат детерминирован для одинаковых входных данных.
- В оценку включаются только проверенные (доступные) ресурсы; исключённые ресурсы явно помечены в отчёте.
