# REQ-NFR-ops.release.canary-kill-switch

**Приоритет:** P1
**Ключевая функция:** cross-cutting (релизы/операции)
**Источник:** quality-matrix audit ячейки 3.3/4.3 (Функции/Аварии — Сопровождение), progressive delivery; урок опыта: Knight Capital 2012 — дефектную функцию не могли остановить 45 минут (нет аварийного выключателя)

**Описание:** Релизы выполняются канареечно (5% → 25% → 100%) с автоматической проверкой на каждом шаге; любая функция может быть аварийно отключена (kill switch) без деплоя; при деградации метрик выполняется автоматический откат.

**Критерии приёмки:**
- Каждая функция, несущая риск, управляется feature flag'ом; время аварийного отключения (kill switch) ≤ 5 минут без деплоя.
- Канареечный релиз: 5% → 25% → 100% трафика; на каждом шаге проверяются метрики (5xx, p95, доля ошибок) в течение ≥ 5 минут.
- Автооткат: при 5xx > 1% или p95 > базового ×2 в течение 5 минут — автоматический откат к предыдущей версии ≤ 10 минут.
- Feature flags удаляются после стабилизации функции (флаг живёт ≤ 2 релизов после включения).
