# REQ-FR-execute.gap.diagnose-root-cause

**Приоритет:** P0
**Ключевая функция:** F2.1
**Источник:** UC-execute.gap.diagnose-root-cause; vision.md F2.1 (P16, P21)
**Описание:** При отставании ученика в модуле (событие `PlanDeviationDetected` по F2.4 или результат проверочных заданий по F2.2 ниже порога освоения) система автоматически выполняет диагностику корневой лакуны: от модуля-симптома выполняется подъём по графу strict-связей (`hasStrictPrerequisite`) вверх по каждой цепочке пререквизитов; первый неосвоенный модуль на цепочке фиксируется как корень лакуны. Если неосвоенных strict-пререквизитов несколько (несколько цепочек) — корневых лакун несколько; система показывает все корневые лакуны и ранжирует их по каскадному влиянию (числу блокируемых модулей и предметов). По результатам формируется объяснение «симптом → корень → эффект разблокировки», закрытие корневой лакуны добавляется в маршрут с приоритетом (F1.1), публикуется событие `RouteRecalculated`, результат направляется родителю/ученику.
**Критерии приёмки:**
- Для каждого модуля-симптома система анализирует 100% цепочек strict-пререквизитов, ведущих к нему (проверка на тестовом подграфе с ≥5 цепочками); корень каждой цепочки — первый неосвоенный модуль (освоение ниже порога с учётом погрешности F2.2 или отсутствие записи освоения), пропуски не допускаются.
- При нескольких неосвоенных пререквизитах выводятся все корневые лакуны, ранжированные по каскадному влиянию: числу блокируемых модулей и предметов (зависимые модули, достижимые из корня по обратным strict-связям); порядок совпадает с эталонным на тестовом наборе ≥10 сценариев.
- Сценарий из vision.md воспроизводится: отставание по «Концентрация растворов» (химия) → корень «Проценты» (освоено 70%) → указаны блокируемые предметы: химия, биология, обществознание.
- Диагностика выполняется за ≤2 с на подграфе до 1000 модулей.
- При отсутствии неосвоенных strict-пререквизитов система помечает отставание как «проблема темпа/нагрузки» и не формирует ложных корневых лакун (A1 UC).
- Закрытие корневой лакуны включается в ближний и средний горизонты маршрута; публикуется событие `RouteRecalculated`; результат диагностики доставляется родителю/ученику с рекомендацией.
