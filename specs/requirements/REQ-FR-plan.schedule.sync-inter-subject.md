# REQ-FR-plan.schedule.sync-inter-subject

**Приоритет:** P2
**Ключевая функция:** F1.10
**Источник:** vision.md F1.10
**Описание:** Расписание вычисляется с учётом межпредметных связей: модули разных предметов выстраиваются в правильном порядке во времени (пример: проект «Экосистема» — проценты по математике осваиваются раньше биологии, использующей проценты для расчёта биомассы; химия и география — в согласованной последовательности). Групповые занятия ставятся в точки схождения маршрутов группы, чтобы каждый ученик приходил подготовленным: к дате занятия закрыты все необходимые strict-пререквизиты (включая межпредметные) у 100% участников.

**Критерии приёмки:**
- Корректность порядка: для каждой межпредметной связи (модуль A предмета X — пререквизит модуля B предмета Y) плановая дата завершения A строго раньше плановой даты начала B — 0 нарушений порядка по всем связям сгенерированного расписания.
- Точки схождения: групповое занятие по модулю M назначается на дату, к которой каждый участник группы закрыл все strict-пререквизиты M (включая межпредметные) — 100% учеников подготовлены к дате занятия; при невозможности занятие переносится на ближайшую дату, когда условие выполняется для 100% участников.
- Детерминированность: для одного и того же набора маршрутов группы и календаря повторный расчёт даёт идентичное расписание (0 расхождений).
- Производительность: межпредметная синхронизация выполняется ≤ 10 с для группы ≤ 30 учеников и суммарно ≤ 300 модулей.
- Приоритет контрольных точек: межпредметный сдвиг не переносит модуль за дату контрольной точки (аттестация, конец четверти) без предупреждения пользователю — 0 переносов без уведомления.
- Непротиворечивость с каскадом: расписание пересчитывается при изменении маршрутов участников (событие `RouteRecalculated`) — 0 устаревших межпредметных привязок после пересчёта маршрута любого участника группы.
