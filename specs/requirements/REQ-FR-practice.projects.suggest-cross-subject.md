# REQ-FR-practice.projects.suggest-cross-subject

**Приоритет:** P1
**Ключевая функция:** F5.2
**Источник:** UC-practice.projects.suggest-cross-subject-projects, vision.md F5.2
**Описание:** Система предлагает обучающемуся идеи проектов, требующих знаний из нескольких тем и/или предметов (cross-subject projects). Для каждой идеи указывается полный перечень необходимых модулей, уровень сложности (complexity) и ожидаемый результат (expected result). Предложения строятся на основе освоенных и доступных модулей, чтобы проект был выполним.
**Критерии приёмки:**
- Каждая идея проекта содержит обязательные поля: перечень необходимых модулей, уровень сложности, описание ожидаемого результата; отсутствие любого поля считается дефектом.
- Кросспредметные идеи требуют модули минимум из 2 разных предметов; на тестовой выборке все предложенные кросспредметные идеи удовлетворяют этому правилу.
- Перечень необходимых модулей полон: для каждой идеи список модулей включает все модули, необходимые для выполнения проекта по данным онтологии (совпадает с эталонным списком на тестовых идеях).
- Уровень сложности градуируется по фиксированной шкале (не менее 3 уровней) и согласован с числом необходимых модулей: идеи с большим числом модулей не получают уровень ниже, чем идеи с меньшим числом модулей.
- Предложение проекта выполняется только при условии, что обучающийся освоил (mastered) или имеет в статусе available не менее 80% необходимых модулей.
