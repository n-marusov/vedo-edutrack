# REQ-FR-execute.gap.cascade-impact

**Приоритет:** P1
**Ключевая функция:** F2.1
**Источник:** vision.md F2.1 (P16)
**Описание:** Визуализация каскадного влияния корневой лакуны (F2.1): система вычисляет множество зависимых модулей, достижимых из корня лакуны по обратным strict-связям (`hasStrictPrerequisite` в обратном направлении), группирует их по предметам и показывает на карте знаний: «лакуна блокирует N модулей в M предметах». Каскадное влияние используется для ранжирования корневых лакун (F2.1) и для объяснения эффекта закрытия: «закрой один модуль — разблокируются M предметов». Для межпредметных цепочек показывается цепочка «корень → симптом» с указанием предметов.
**Критерии приёмки:**
- Для каждой корневой лакуны вычислено каскадное влияние: N — число блокируемых модулей (зависимые модули, достижимые по обратным strict-связям), M — число предметов; результат совпадает с эталонным обходом графа на тестовом наборе ≥10 сценариев (расхождение 0).
- Вычисление каскадного влияния выполняется за ≤2 с на подграфе до 1000 модулей.
- Карта знаний отображает для каждой лакуны метку «N модулей, M предметов»; визуализация обновляется при пересчёте диагностики (событие `RouteRecalculated`).
- Ранжирование корневых лакун по каскадному влиянию (N и M) совпадает с эталонным порядком на тестовом наборе; верхние позиции занимают лакуны с наибольшим числом блокируемых модулей и предметов.
- Для межпредметной цепочки (корень в другом предмете) отображается путь «корень → симптом» с указанием предметов на каждом шаге.
- Объяснение эффекта закрытия формируется по шаблону «закрой модуль X — разблокируются M предметов (перечень)»; сценарий vision.md (Проценты → химия, биология, обществознание) воспроизводится корректно.
