# REQ-FR-plan.gap.analyze-to-goal

**Приоритет:** P1
**Ключевая функция:** F1.5
**Источник:** UC-plan.gap.analyze-gap-to-goal; vision.md F1.5 (P: «непонятно, что именно нужно для роли и сколько времени это займёт»)
**Описание:** Система отвечает на вопрос «что нужно освоить для роли X, чего ещё нет»: анализ разрыва между текущей позицией ученика и целевой ролью/целью. Вход: текущая позиция (освоенные модули с уровнями) + целевая роль (роль / экзамен / проект / тема / разряд / уровень / допуск) + контекст обучения. Выход: список необходимых неосвоенных модулей (сгруппированный по предметам и горизонтам), критический путь до цели, оценка времени (с учётом темпа ученика и доступной недельной нагрузки) и оценка стоимости ресурсов (F1.4). Отличие от диагностики лакун (F2.1): разрыв до цели — на будущее, а не корень текущего отставания. Отчёт доступен через GUI и API, предлагается переход к построению маршрута (UC-plan.compute.shortest-path-to-goal).

**Критерии приёмки:**
- Полнота: список необходимых модулей включает 100% неосвоенных модулей, лежащих хотя бы на одном пути strict-связей от позиции ученика к цели; освоенные модули в список не включаются (пропущенных = 0, ложных = 0).
- Критический путь построен по strict-связям и включает essential-модули ядра контекста (F1.1.4): 100% модулей критического пути обязательны для минимального срока достижения цели (для эталонного набора из ≥20 сценариев совпадение с переборным решением).
- Точность оценки времени: для контрольного набора из ≥20 сценариев (позиция, цель, темп, недельная нагрузка) оценка отличается от эталонного расчёта (сумма оценок времени модулей с учётом темпа) не более чем на ±10%.
- Недостижимость цели (A1): модули, недостижимые из позиции по strict-связям, помечаются «недоступно» с перечислением недостающих пререквизитов — 100% недостижимых модулей помечены, 0 молчаливых пропусков.
- Превышение срока (A4): при оценке времени, большей доступного срока до дедлайна, отчёт содержит предупреждение о невыполнимости и ≥ 1 альтернативу (сокращение цели, увеличение нагрузки, выбор приоритетной части) — 0 отчётов с невыполнимой оценкой без предупреждения.
- При наличии зафиксированного плана отчёт дополнительно выводит дельту «план vs разрыв до цели» (0 отчётов без дельты при существующем плане).
