### UC-viz.builder.construct-route-visually: Визуальный конструктор маршрута

**Актор:** Родитель / Ученик / Методист
**Приоритет:** P0
**Ключевая функция:** F4.3
**Канал:** GUI
**Описание:** Конструктор маршрутов: выбор цели (профессия / проект / экзамен) → визуализация маршрута → оценка времени → подтверждение → фиксация плана. Новый пользователь строит маршрут за ≤ 5 минут (G3).
**Основной поток:**
1. Пользователь открывает конструктор маршрутов и выбирает тип цели: профессия, проект или экзамен.
2. Пользователь задаёт параметры цели и контекст: целевая роль/тема/экзамен, возраст/класс, педагогическая концепция (F1.7), формальные рамки (F1.11).
3. Система вычисляет маршрут как функцию: копирует релевантный подграф онтологии через API VEDO Hub и выполняет алгоритм маршрутизации с весами связей (F1.1).
4. Система визуализирует маршрут на карте знаний: критический путь (essential + strict), ближний/средний/дальний горизонты (F1.3).
5. Система показывает оценку времени: суммарная длительность с буфером на темп ученика (F1.1.5) и оценку затрат маршрута (F3.4).
6. Пользователь корректирует параметры (цель, концепцию, темп) — система пересчитывает маршрут и обновляет визуализацию в реальном времени.
7. Пользователь подтверждает маршрут — система фиксирует план на контрольной точке (F1.8): маршрут + временные метки.
8. Система отображает два слоя после фиксации: «что рекомендуем сейчас» (маршрут) и «что запланировали» (план), и запускает каскад обновления ресурсов и рекомендаций (F1.6).
**Альтернативные потоки:**
- A1: Цель недостижима (нет связей до целевого модуля) — система объясняет причину и предлагает ближайшие достижимые цели.
- A2: Маршрут слишком длинный для горизонта планирования — система предлагает сокращённый набор (исключение enrich, перенос soft) с показом дельты по времени.
- A3: Пользователь отменяет подтверждение — маршрут остаётся рекомендацией без фиксации плана, прогресс продолжает измеряться от старого плана (F1.9).
- A4: Уже существует зафиксированный план с существенными отличиями (>15% модулей или >2 недель экономии) — система показывает дельту «план vs актуальный маршрут» и предлагает пересмотр (F1.9).
**Постусловия:** Маршрут вычислен и визуализирован; оценка времени и затрат показана; при подтверждении план зафиксирован на контрольной точке с временными метками; каскад F1.6 выполнен (подборка ресурсов, рекомендации историй/проектов).
**Источник требований:** vision.md F4.3, F1.1 (P1 — родитель не знает порядок тем; P15 — темп ученика конфликтует с расписанием; G3 — маршрут за 5 минут)
