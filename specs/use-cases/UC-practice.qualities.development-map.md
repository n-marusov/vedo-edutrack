### UC-practice.qualities.development-map: Карта качеств и осознанный отбор

**Актор:** Методист / Завуч
**Приоритет:** P2
**Ключевая функция:** F5.4
**Канал:** GUI
**Описание:** Карта качеств показывает, какие качества (эмпатия, мужество, ответственность и др.) развивает каждый модуль через маркировку develops. Поддерживает целевые качества («хочу развить эмпатию») и покрытие программы воспитания (8 направлений ФГОС). Закрывает разрыв между учебным планом и рабочей программой воспитания (P22).
**Основной поток:**
1. Методист/завуч открывает «Карту качеств» для выбранного контекста: модуль, предмет, класс или вся школа.
2. Система отображает качества, развиваемые каждым модулем (маркировка develops из онтологии), в виде карты «модуль ↔ качества».
3. Система накладывает целевые качества: если задана цель «развить эмпатию», модули с маркировкой develops=эмпатия получают приоритет в маршруте (F1.1, приоритет как функция контекста).
4. Система показывает покрытие программы воспитания: 8 направлений (гражданское, патриотическое, духовно-нравственное, эстетическое, трудовое, экологическое, физическое, ценности научного познания) и долю закрытых направлений текущим набором модулей.
5. Система подсвечивает непокрытые направления и предлагает модули/произведения, закрывающие эти направления (осознанный отбор произведений в маршрут).
6. Методист просматривает разрезы: качество → модули → предметы; направление воспитания → покрытие по классам.
7. Методист экспортирует сводку покрытия программы воспитания для отчётности (проверяющим, родителям).
8. Система сохраняет контекст и обновляет покрытие при изменении маршрутов.
**Альтернативные потоки:**
- A1: Направление воспитания не покрыто ни одним модулем — система показывает дефицит и предлагает кандидатов из онтологии с маркировкой develops по этому направлению.
- A2: Целевые качества не заданы — система показывает только карту develops и покрытие программы воспитания без приоритизации.
- A3: Маркировка develops отсутствует у модуля — модуль отображается без привязки к качествам и помечается «нет данных», карта не строится по нему.
**Постусловия:** Карта «модуль ↔ качества» отображена; покрытие программы воспитания рассчитано по 8 направлениям; непокрытые направления подсвечены с предложениями; выбранные целевые качества влияют на приоритет модулей; сводка экспортирована без изменения данных.
**Источник требований:** vision.md F5.4 (P22 — программа воспитания оторвана от учебного плана; G4 — формальная отчётность по ФГОС и программе воспитания)
