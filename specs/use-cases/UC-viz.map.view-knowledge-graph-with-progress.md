### UC-viz.map.view-knowledge-graph-with-progress: Просмотр карты знаний с прогрессом

**Актор:** Ученик / Родитель
**Приоритет:** P0
**Ключевая функция:** F4.1
**Канал:** GUI
**Описание:** Пользователь открывает 2D-карту знаний: темы — узлы, зависимости — рёбра. Цветовая кодировка статуса: освоено (зелёный), в процессе (жёлтый), доступно (синий), заблокировано (серый). Незакрытые пререквизиты подсвечены красным с каскадными стрелками влияния. Доступны два режима: «Критический путь» (essential + strict) и «Исследование» (полный граф).
**Основной поток:**
1. Пользователь открывает «Карту знаний» из личного кабинета ученика или из кабинета родителя.
2. Система запрашивает через API VEDO Hub релевантный подграф онтологии (F1.1) и накладывает на него прогресс ученика (освоенные модули, F2.2).
3. Система отрисовывает 2D-граф: узлы — темы, рёбра — зависимости; статусы окрашиваются: освоено — зелёный, в процессе — жёлтый, доступно — синий, заблокировано — серый.
4. Незакрытые пререквизиты отображаются красным; при клике на красный узел система показывает стрелки каскадного влияния вниз по графу: «Эта лакуна блокирует 4 темы в 3 предметах».
5. Пользователь переключает режимы одним кликом: «Критический путь» — только essential-модули и strict-связи (минимальный набор для достижения цели); «Исследование» — полный граф с enriches, appliesTo, историями и проектными идеями.
6. Пользователь применяет фильтр по предметам/контексту — граф перестраивается с сохранением статусов.
7. Пользователь кликает узел — система показывает карточку модуля: статус освоения, пререквизиты, привязанные ресурсы (F3.1), связи с ФГОС (F2.3).
8. Система сохраняет выбранный режим и фильтры как персональные настройки отображения.
**Альтернативные потоки:**
- A1: Граф слишком велик (режим «Исследование») — система группирует узлы по предметам с раскрытием по клику и визуальной сверткой дальних горизонтов.
- A2: У ученика нет текущей цели — система показывает карту по контексту по умолчанию (текущий класс/программа) без критического пути.
- A3: Данные прогресса частично устарели (последняя проверка > N дней) — система помечает узел «в процессе» с пометкой даты и предлагает пройти проверочное задание (F2.2).
**Постусловия:** Карта знаний отображена с актуальным прогрессом и цветовой кодировкой; красные узлы с каскадными стрелками указывают незакрытые пререквизиты; режим «Критический путь» и «Исследование» переключаемы; фильтры и настройки сохранены.
**Источник требований:** vision.md F4.1 (P6 — непрозрачность прогресса; P3 — ручная сверка с ФГОС; P16 — лакуны невидимы до аттестации)
