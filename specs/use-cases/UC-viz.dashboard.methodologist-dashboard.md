### UC-viz.dashboard.methodologist-dashboard: Дашборд методиста / школы

**Актор:** Методист / Директор школы
**Приоритет:** P1
**Ключевая функция:** F4.5
**Канал:** GUI
**Описание:** Дашборд методиста/директора: покрытие ФГОС по классу и школе, групповая аналитика (какие темы — основные точки отставания), вклад в онтологию. Даёт мгновенную сводку по школе вместо ручных таблиц и планёрок (P18).
**Основной поток:**
1. Методист/директор открывает дашборд с выбором контекста: класс, параллель или вся школа.
2. Система агрегирует покрытие ФГОС по выбранному контексту: доля закрытых требований по классам и предметам (F2.7).
3. Система показывает групповую аналитику: темы, по которым максимальная доля учащихся отстаёт или не освоила модуль (точки отставания), с числом затронутых учащихся.
4. Система подсвечивает классы/группы под риском неаттестации (F2.7.3) с прогнозом по контрольной точке.
5. Система показывает сводку по лакунам: корневые лакуны, повторяющиеся у многих учащихся (агрегированный F4.6).
6. Система отображает вклад методиста в онтологию: добавленные темы/связи, статусы предложений на слияние (F6.2-чтение, форк-модель VEDO Hub).
7. Директор/методист переходит от сводки к конкретному учащемуся или классу (панель группы, F4.7).
8. Система сохраняет контекст просмотра и экспортирует сводку (отчётность родителям/проверяющим).
**Альтернативные потоки:**
- A1: Контекст пуст (нет данных о покрытии) — система показывает пустые состояния с подсказкой проверить привязку модулей к ФГОС.
- A2: Требуется разрез «по предмету» — система перестраивает аналитику: покрытие и отставания по одному предмету во всех классах.
- A3: Сводка экспортируется в файл — выгружается отчёт с датой и контекстом без изменения данных системы.
**Постусловия:** Дашборд отображает покрытие ФГОС по контексту, точки отставания, группы под риском и вклад в онтологию; переход к панели группы и личным кабинетам учащихся работает; экспорт сформирован без изменения данных.
**Источник требований:** vision.md F4.5 (P18 — директор видит 5 изолированных «огородов» вместо школы; P13 — дублирование работы методистов при обновлении ФГОС)
