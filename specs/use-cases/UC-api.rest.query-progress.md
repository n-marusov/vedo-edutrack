### UC-api.rest.query-progress: Запрос прогресса учащегося через REST API

**Актор:** EdTech-платформа
**Приоритет:** P1
**Ключевая функция:** F6.1
**Канал:** API
**Описание:** Внешняя EdTech-платформа запрашивает прогресс учащегося через `GET /progress/{learner_id}`: освоенные модули, текущая позиция, план и факт, темп — для отображения в своей UI и аналитики. Данные о прогрессе формируются EduTrack из событий освоения (F2.1-F2.4).
**Основной поток:**
1. API-клиент аутентифицируется и отправляет `GET /progress/{learner_id}` с опциональными параметрами фильтрации (предмет, период).
2. Система проверяет права клиента на учащегося и валидирует идентификатор.
3. Система собирает актуальный прогресс: список освоенных модулей с датами, текущий модуль (в процессе), статусы освоения с погрешностью оценки (F2.2).
4. Система добавляет план и факт: плановые vs фактические даты по модулям плана, отклонения в днях и причины (F2.4).
5. Система добавляет производные показатели: темп (модулей/недель), долю плана выполненную, прогноз до контрольной точки (F2.5).
6. Система возвращает ответ (JSON): позиция, прогресс по модулям, план-факт, темп, прогноз, версия данных прогресса.
7. API-клиент отображает прогресс в своей платформе и при необходимости подписывается на вебхук plan.deviated (F6.4) для своевременных обновлений.
**Альтернативные потоки:**
- A1: Учащийся не найден или клиент не имеет прав — система возвращает 404/403 с понятным описанием.
- A2: План не зафиксирован — раздел «план и факт» возвращает только факт с флагом `plan_fixed: false`.
- A3: Прогресс устарел (нет событий > N дней) — система возвращает данные с меткой актуальности и рекомендацией выполнить проверочное задание (F2.2).
- A4: Данные меняются во время запроса (событие module.mastered) — система возвращает консистентный снимок с указанием версии.
**Постусловия:** Прогресс учащегося возвращён клиенту с план-фактом, темпом и прогнозом; данные соответствуют последнему зафиксированному снимку; запрос не модифицирует состояние системы.
**Источник требований:** vision.md F6.1 (P8 — платформа не знает школьный прогресс ученика; G2 — единое API прогресса для платформ)
