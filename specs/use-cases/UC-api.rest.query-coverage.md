### UC-api.rest.query-coverage: Запрос покрытия ФГОС через REST API

**Актор:** EdTech-платформа
**Приоритет:** P1
**Ключевая функция:** F6.1
**Канал:** API
**Описание:** Внешняя EdTech-платформа запрашивает покрытие формальной рамки через `GET /fgos/coverage/{learner_id}`: доля закрытых требований ФГОС/профстандарта, дефициты с приоритетом, прогноз покрытия к контрольной точке. Расчёт выполняется по алгоритму F2.7.
**Основной поток:**
1. API-клиент аутентифицируется и отправляет `GET /fgos/coverage/{learner_id}` с опциональными параметрами (рамка, дата контрольной точки).
2. Система проверяет права клиента и валидирует идентификатор учащегося и рамку.
3. Система собирает привязки освоенных модулей к требованиям рамки (F2.3) и рассчитывает покрытие: `coverage = закрытые требования / всего требований для контекста` (F2.7.1).
4. Система рассчитывает дефициты: незакрытые требования с приоритетом (жёсткий пререквизит > ядро > опциональное, F2.7).
5. Система рассчитывает прогноз покрытия к контрольной точке: `projected = (освоенные + в процессе × factor) / всего` (F2.7.2) и уровень риска (F2.7.3).
6. Система формирует минимальный закрывающий набор модулей для достижения целевого покрытия (F2.7.4).
7. Система возвращает ответ (JSON): покрытие, дефициты с приоритетами, прогноз, уровень риска, минимальный закрывающий набор, версия данных.
8. API-клиент использует ответ для отчётности и рекомендаций в своей платформе.
**Альтернативные потоки:**
- A1: Учащийся вне школьного контекста (профстандарт) — рамка определяется параметром запроса, покрытие считается по требованиям роли.
- A2: Нет контрольной точки в параметрах — прогноз считается к ближайшей формальной границе (конец периода).
- A3: Требования рамки обновились в онтологии — ответ содержит пометку о версии рамки и пересчитанное покрытие по новой версии.
**Постусловия:** Покрытие рамки, дефициты, прогноз и минимальный закрывающий набор возвращены клиенту; расчёт выполнен по актуальной версии рамки и прогресса; запрос не модифицирует состояние системы.
**Источник требований:** vision.md F6.1, F2.7 (P3 — ручная сверка с ФГОС в Excel; P14 — разрыв «живого» знания и формальной рамки; G4 — формальная отчётность за ≤ 1 сек)
