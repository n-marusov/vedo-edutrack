### UC-plan.resource.match-resources-to-steps: Подбор ресурсов к шагам маршрута

**Актор:** Система
**Приоритет:** P1
**Ключевая функция:** F1.4
**Канал:** Schedule
**Описание:** Для каждого шага маршрута — подбор всех доступных ресурсов: учебные материалы (контент-ресурсы: видео, статьи, интерактивы, учебники), репетиторы/наставники, оборудование, доступы (ресурсы обеспечения) — с фильтром по стилю обучения, формату, сложности, длительности и бюджету (F3.2). Подбор обновляется при каскаде пересчёта маршрута (F1.6): маршрут → план → ресурсы.

**Основной поток:**
1. Планировщик (Schedule) запускает подбор ресурсов: после пересчёта маршрута (событие `RouteRecalculated`), фиксации плана (`PlanFixed`) или при изменении профиля ученика.
2. Система получает актуальный маршрут: упорядоченные шаги с модулями и глубиной прохождения.
3. Система загружает профиль ученика: стиль обучения, предпочитаемые форматы, ограничения по длительности, сложности и бюджету (F3.2).
4. Для каждого шага система запрашивает из онтологии (F0.1, F3.1) ресурсы, привязанные к модулю: контент-ресурсы и ресурсы обеспечения, с типом, форматом, стилем, стоимостью и источником.
5. Система фильтрует ресурсы по профилю ученика: формат (например, видео до 20 минут), стиль, сложность, длительность, стоимость в пределах бюджета.
6. Система проверяет доступность ресурсов обеспечения (F3.3): наличие репетитора, оборудования, доступа, бюджета; недоступные ресурсы помечаются, предлагаются альтернативы (дороже/быстрее, дешевле/дольше).
7. Система привязывает подобранные ресурсы к шагам маршрута и обновляет подборку; пересчитываются затраты по маршруту (F3.4) и сверяются с бюджетом.
8. Подборка публикуется в маршруте (GUI/API): каждый шаг содержит список ресурсов с пометками доступности и альтернативами.

**Альтернативные потоки:**
- A1: **Нет ресурсов под фильтр** — для шага нет ресурсов, удовлетворяющих профилю; система расширяет фильтр (снимает необязательные критерии) и помечает шаг как «ресурсы не подобраны», предлагая дефолтные материалы.
- A2: **Ресурс недоступен (физически)** — репетитор занят или оборудование недоступно в нужные даты; система предлагает альтернативы по времени/цене (F3.3) и учитывает ограничение при расписании.
- A3: **Превышение бюджета** — суммарная стоимость ресурсов превышает бюджет маршрута; система предлагает более дешёвые альтернативы и показывает экономику выбора (F3.4).
- A4: **Изменение маршрута** — маршрут пересчитан (освоен модуль, смена цели); подборка пересчитывается по каскаду F1.6, устаревшие привязки ресурсов удаляются.

**Постусловия:** Каждый шаг маршрута обеспечен подборкой ресурсов, отфильтрованной по стилю, формату, сложности, длительности и бюджету ученика; доступность ресурсов проверена; альтернативы предложены для недоступных; затраты по маршруту пересчитаны и сверены с бюджетом; подборка опубликована и связана с версией маршрута.

**Источник требований:** vision.md F1.4 (P: «непонятно, на каких материалах проходить модуль»), F1.6 (каскад), F3.2–F3.4
