### UC-resource.budget.estimate-route-budget: Оценка затрат и бюджета маршрута

**Актор:** Родитель / Методист
**Приоритет:** P1
**Ключевая функция:** F3.4
**Канал:** GUI
**Описание:** Пользователь оценивает стоимость ресурсов по всему маршруту (учебные материалы, репетиторы, оборудование, доступы), сравнивает с установленным бюджетом и анализирует экономику маршрута: «за сколько и с помощью чего» будет достигнута цель.
**Основной поток:**
1. Пользователь открывает раздел «Бюджет маршрута» из карточки маршрута или из личного кабинета.
2. Система агрегирует стоимость всех ресурсов по шагам маршрута: контент-ресурсы и ресурсы обеспечения (F3.1), разбивая по категориям (материалы, репетиторы, оборудование, доступы).
3. Система показывает сводку: итоговая стоимость маршрута, стоимость в месяц, распределение по периодам до контрольной точки, долю каждой категории.
4. Пользователь задаёт (или система подставляет из профиля) бюджет на период и цель.
5. Система сравнивает оценку с бюджетом: «в пределах бюджета» либо «превышение на X ₽», и показывает, какие шаги/категории создают превышение.
6. Система предлагает варианты экономии: замена «дороже/быстрее» на «дешевле/дольше» (F3.3), исключение enrich-модулей, перенос ресурсоёмких шагов.
7. Пользователь выбирает вариант — система пересчитывает оценку бюджета и обновляет план.
8. Система фиксирует итоговый бюджет маршрута и учитывает его при проверке доступности ресурсов (F3.3).
**Альтернативные потоки:**
- A1: Бюджет не задан — система показывает только оценку затрат и среднемесячные ожидания без сверки.
- A2: Превышение бюджета неустранимо без смены цели — система показывает разницу между целями (например, «цель X: 90 тыс. ₽; цель Y: 55 тыс. ₽») и предлагает выбор.
- A3: Методист просматривает бюджет группового маршрута (класс/группа) — система агрегирует по учащимся и выделяет общие ресурсы, которые можно разделить.
**Постусловия:** Оценка затрат маршрута рассчитана и сохранена; сверка с бюджетом выполнена; выбранные варианты экономии отражены в подборке ресурсов и плане; итоговый бюджет является входом для проверки доступности (F3.3).
**Источник требований:** vision.md F3.4 (P20 — бюджет не планируется, обеспечение непредсказуемо; P1 — избыточные траты на пересекающиеся материалы)
