### UC-viz.panel.group-management-panel: Панель управления группой учащихся

**Актор:** Родитель / Директор / HR
**Приоритет:** P1
**Ключевая функция:** F4.7
**Канал:** GUI
**Описание:** Обзорный дашборд для управления маршрутами группы учащихся: родитель видит всех детей на семейном обучении, директор — класс/школу, HR — сотрудников на онбординге. Для каждого учащегося — мини-карточка: имя, текущий модуль, покрытие ФГОС, прогноз до контрольной точки, флаг «требует внимания». Доступно быстрое переключение в личный кабинет и сводная аналитика по группе.
**Основной поток:**
1. Пользователь открывает панель управления группой; система определяет ролевой контекст: родитель — свои дети, директор — своя школа, HR — свой департамент.
2. Система формирует список учащихся группы с мини-карточками: имя, текущий модуль, покрытие ФГОС/профстандарта, прогноз до контрольной точки, флаг «требует внимания» (по F2.5, F2.6).
3. Карточки, требующие внимания (прогноз «под риском»/«не успевает», отставание > N дней), визуально выделяются и сортируются вверх.
4. Система показывает сводную аналитику по группе: «5 из 80 учеников под риском неаттестации по математике», «средний темп по классу — 85% от плана».
5. Пользователь кликает на мини-карточку — система открывает личный кабинет (дашборд F4.2/F4.4) соответствующего учащегося.
6. Пользователь возвращается в панель — система сохраняет позицию списка и применённые фильтры.
7. Пользователь применяет фильтры (предмет, статус прогноза, период до контрольной точки) — список и аналитика пересчитываются.
8. Система периодически обновляет панель при поступлении событий прогресса (module.mastered, plan.deviated).
**Альтернативные потоки:**
- A1: Группа пуста (родитель без детей/учащихся в контексте) — система показывает пустое состояние и приглашение добавить учащегося.
- A2: Флаг «требует внимания» у многих (>30% группы) — система группирует по причинам (тема, лакуна) и показывает корневые паттерны по группе (агрегированный F4.6).
- A3: HR-сценарий — вместо покрытия ФГОС карточки показывают покрытие ролевых требований и прогресс до выхода на продуктивность.
**Постусловия:** Панель отображает мини-карточки всех учащихся ролевого контекста с прогнозами и флагами; сводная аналитика по группе рассчитана; переключение в личные кабинеты работает; данные обновляются по событиям прогресса.
**Источник требований:** vision.md F4.7 (P17 — семья с несколькими детьми без единой панели; P18 — директор без сводки по школе; P19 — HR без панели по 50 новичкам)
