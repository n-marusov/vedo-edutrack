### UC-api.sparql.read-only: Read-only запросы к графу знаний через SPARQL

**Актор:** EdTech-платформа / Аналитик
**Приоритет:** P1
**Ключевая функция:** F6.2
**Канал:** API
**Описание:** Внешние клиенты выполняют прямые read-only SPARQL-запросы к графу знаний: «доступные модули», «кратчайший путь», «дефициты», «ресурсы по теме». Доступ с аутентификацией и rate limiting; запросы не модифицируют онтологию VEDO Hub.
**Основной поток:**
1. Аналитик/платформа аутентифицируется (API-ключ / OAuth) и отправляет SPARQL-запрос SELECT на read-only endpoint.
2. Система проверяет права клиента и тип запроса: разрешены только чтение (SELECT, ASK, CONSTRUCT для выборки) — запросы UPDATE/DELETE/INSERT отклоняются.
3. Система проверяет rate limit клиента (частота и объём запросов) и, при превышении, отклоняет запрос с 429.
4. Система выполняет запрос к графу знаний (онтология VEDO Hub через API) с тайм-аутом и ограничением размера результата.
5. Система возвращает результаты в формате SPARQL JSON/XML с метаданными: время выполнения, версия графа, стоимость запроса.
6. Клиент использует результаты: например, «доступные модули» для предварительного фильтра, «кратчайший путь» для собственной аналитики, «ресурсы по теме» для подборок.
7. Система журналирует запрос (клиент, шаблон, объём) для контроля использования и аномалий.
**Альтернативные потоки:**
- A1: Некорректный SPARQL-синтаксис — система возвращает ошибку парсинга с указанием позиции и примером корректного запроса.
- A2: Запрос сложный (длинный путь вычисления) — система ограничивает время выполнения, возвращает частичный результат с пометкой и рекомендует уточнить паттерн.
- A3: Клиент превысил rate limit — система возвращает 429 с Retry-After и сведениями о квоте.
- A4: Попытка модифицирующего запроса — система отклоняет запрос с 403 и инструкцией по использованию форк-модели VEDO Hub для изменений.
**Постусловия:** Выполнены только read-only запросы к графу знаний; результаты возвращены с метаданными версии графа; модифицирующие запросы отклонены; использование клиента учтено в rate limiting и журнале; онтология VEDO Hub не изменена.
**Источник требований:** vision.md F6.2 (P7 — изолированные графы платформ; P12 — карта знаний методиста в Excel; G2 — платформы используют общий граф)
