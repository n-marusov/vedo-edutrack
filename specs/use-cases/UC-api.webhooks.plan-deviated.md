### UC-api.webhooks.plan-deviated: Уведомление о событии plan.deviated

**Актор:** Система
**Приоритет:** P1
**Ключевая функция:** F6.4
**Канал:** Webhook
**Описание:** При обнаружении отклонения от плана (отставание > N дней или ускорение) система отправляет внешнему подписчику webhook-событие `plan.deviated` с рекомендацией. Доставка идемпотентна: дублирование событий не ломает состояние подписчика и EduTrack.
**Основной поток:**
1. Триггер: событие прогресса (module.mastered, подтверждение проверочного задания) или Schedule-проверка отклонений (F2.4).
2. Система пересчитывает план и факт: плановая vs фактическая дата по модулям, отклонение в днях, причина (ускорение / требовалось больше практики / перерыв).
3. Система сравнивает отклонение с порогом (> N дней, N настраивается) и определяет статус: отклонение есть / отклонение устранено.
4. Система формирует payload события `plan.deviated`: event_id (уникальный), learner_id, module_id, отклонение в днях, причина, статус прогноза (F2.5), рекомендация (F2.6), версия плана.
5. Система отправляет событие подписчикам (HR/LMS/родительский сервис) с подписью (HMAC).
6. Подписчик подтверждает приём (HTTP 2xx) — событие помечается доставленным.
7. При недоставке система повторяет доставку с экспоненциальной задержкой; при дубликате того же event_id подписчик игнорирует повторную обработку (идемпотентность).
8. Система журналирует доставку; состояние отклонений обновлено до «уведомлено».
**Альтернативные потоки:**
- A1: Отклонение устранено до отправки (ученик догнал план) — система отменяет формирование события, состояние возвращается в норму без уведомления.
- A2: Webhook-URL недоступен — повторные попытки; после лимита событие помечается «недоставлено» с сохранением payload для ручной отправки.
- A3: Подписчик вернул 4xx — событие помечается «отклонено», payload сохраняется для анализа.
- A4: План пересчитан (новая фиксация F1.9) и отклонение исчезло — система отправляет компенсирующее событие с признаком `deviated: false` и тем же correlation_id.
**Постусловия:** Событие `plan.deviated` доставлено подписчикам или корректно помечено; рекомендации по отклонению сформированы (F2.6); повторные доставки не изменяют состояние; журнал доставки доступен для аудита.
**Источник требований:** vision.md F6.4, F2.4, F2.6 (P6 — непрозрачность прогресса; P19 — HR узнаёт об отставании с задержкой; P18 — задержка реакции директора неделю)
