### UC-viz.map.view-gap-diagnostic-map: Просмотр диагностической карты лакун

**Актор:** Родитель / Методист
**Приоритет:** P0
**Ключевая функция:** F4.6
**Канал:** GUI
**Описание:** Диагностический вид карты знаний: отображаются только корневые лакуны (первый неосвоенный пререквизит в цепочке strict-связей) и их каскадные связи. Корневые лакуны ранжируются по каскадному влиянию — числу блокируемых модулей и предметов. Заменяет ручную сверку в Excel (P16).
**Основной поток:**
1. Пользователь открывает «Карту знаний» и переключается в режим «Лакуны» (подрежим критического пути) одним кликом.
2. Система запускает диагностику: поднимается по графу strict-связей вверх по каждой цепочке пререквизитов от точек отставания и находит первый неосвоенный модуль в каждой цепочке — корневую лакуну (алгоритм F2.1).
3. Система отображает только корневые лакуны красными узлами; рядом — зелёные узлы освоенных модулей, которые разблокируются при закрытии лакуны.
4. Система рисует каскадные стрелки от каждой лакуны к зависимым темам и предметам.
5. Система ранжирует лакуны по каскадному влиянию (число блокируемых модулей и предметов) и показывает ранжированный список: «эта лакуна блокирует 4 предмета, а эта — 1».
6. Пользователь кликает лакуну — система показывает пояснение: корень проблемы, блокируемые темы, рекомендуемый порядок закрытия, ожидаемый эффект («закрой это — разблокируются эти три темы»).
7. Пользователь переходит к действию: назначает модуль лакуны приоритетным в плане или открывает подборку ресурсов для его закрытия (F3.2).
**Альтернативные потоки:**
- A1: Корневых лакун нет — система показывает «все пререквизиты освоены» и переводит карту в режим просмотра обычного прогресса.
- A2: Одна лакуна блокирует целые предметы — каскадные стрелки сворачиваются до уровня предметов с раскрытием по клику.
- A3: Лакуна появилась недавно (обновление онтологии добавило strict-связь) — узел помечается «новая связь», с датой изменения из онтологии.
**Постусловия:** На карте отображены только корневые лакуны с каскадными стрелками, ранжированные по влиянию; для каждой лакуны доступны пояснение и переход к действиям (приоритизация в плане, подбор ресурсов); состояние «Лакуны» открыто без ручной сверки данных.
**Источник требований:** vision.md F4.6, F2.1 (P16 — Марина лечит симптомы вместо корня; P3 — стрессовый штурм перед аттестацией)
