### UC-resource.catalog.filter-by-format: Фильтрация каталога ресурсов по формату

**Актор:** Ученик / Родитель
**Приоритет:** P0
**Ключевая функция:** F3.2
**Канал:** GUI
**Описание:** Пользователь просматривает каталог контент-ресурсов, привязанных к модулям маршрута, и фильтрует их по формату (video / text / interactive / textbook) и источнику, чтобы выбрать подходящий учебный материал для текущего шага.
**Основной поток:**
1. Пользователь открывает каталог ресурсов из карточки шага маршрута или из дашборда ученика.
2. Система отображает каталог: контент-ресурсы с атрибутами (формат, стиль, сложность, длительность, стоимость, источник) и ресурсы обеспечения (репетитор, оборудование, доступ, деньги) — согласно привязке ресурсов к модулям (F3.1).
3. Пользователь задаёт фильтр по формату: video, text, interactive или textbook (допускается несколько значений).
4. Пользователь дополнительно задаёт фильтр по источнику (например, конкретная EdTech-платформа или издательство).
5. Система применяет фильтры и показывает только подходящие ресурсы, отсортированные по релевантности к текущему модулю.
6. Пользователь открывает карточку ресурса: длительность, стоимость, оценка сложности, стиль подачи, ссылка на источник.
7. Пользователь выбирает ресурс — система прикрепляет его к текущему шагу маршрута как предпочтительный материал.
8. Система сохраняет выбор и обновляет подборку ресурсов шага (каскад F1.6).
**Альтернативные потоки:**
- A1: Фильтр не дал результатов — система показывает пустое состояние с подсказкой снять часть фильтров или предлагает ресурсы ближайшего формата («похожее: интерактив вместо видео»).
- A2: Пользователь не выбирает ресурс, а только просматривает каталог — выбор не сохраняется, состояние маршрута не меняется.
- A3: Ресурс недоступен (заблокирован по доступности F3.3) — карточка помечается «недоступен», выбор блокируется, предлагаются альтернативы.
**Постусловия:** Каталог отфильтрован по выбранным форматам и источникам; выбранный ресурс прикреплён к шагу маршрута и учтён в подборке ресурсов и оценке бюджета; состояние каталога (фильтры) восстановимо при повторном открытии.
**Источник требований:** vision.md F3.2, F3.1 (P1 — неоптимальные маршруты и пересечение материалов; P20 — непредсказуемая обеспеченность ресурсами)
