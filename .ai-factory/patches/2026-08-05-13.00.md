# Bypass browser HSTS cache by moving Traefik HTTP to port 8081

**Date:** 2026-08-05 13:00
**Files:** deploy/docker-compose.yml, deploy/traefik/traefik.yml, deploy/traefik/dynamic.yml, Makefile, README.md, deploy/README.md
**Severity:** medium

## Problem

Accessing http://localhost (port 80) automatically redirected to https://localhost
even after the Traefik HTTP->HTTPS redirect was removed. The redirect happened at
the browser level — the browser cached `Strict-Transport-Security: max-age=31536000`
(1 year) from the original Traefik config and silently upgraded HTTP to HTTPS
before any request reached the server.

## Root Cause

Two layers:

1. **Original Traefik config** had `redirections.entryPoint.to: websecure` (HTTP->
   HTTPS redirect) AND `forceSTSHeader: true` with `stsSeconds: 31536000`. The
   HSTS header poisoned browser cache for 1 year.

2. **Browser HSTS enforcement** cannot be overridden by the server — once the
   browser stores HSTS for `localhost`, every `http://localhost` request is
   internally upgraded to `https://localhost` with no network round-trip. Removing
   the redirect on the server side has no effect.

## Solution

1. **docker-compose.yml**: Changed Traefik HTTP port mapping from `"80:80"` to
   `"${TRAEFIK_HTTP_PORT:-8081}:80"`. Chrome (and other browsers) only apply
   HSTS upgrade to the default HTTP port 80; non-standard ports are not upgraded.
   Also added `TRAEFIK_HTTPS_PORT` variable (default 4433) for symmetry.

2. **traefik.yml**: Removed the HTTP->HTTPS redirect. Added comments explaining
   the port workaround. Traefik container still listens on port 80 internally.

3. **dynamic.yml**: All routers listen on `["web", "websecure"]`. TLS is
   disabled for dev. HSTS headers are disabled. Added `Host('localhost')` to
   SPA router rule.

4. **Makefile**: Updated `dev` target to print `http://localhost:8081`.
   Updated Makefile comments.

5. **README.md**: Updated URL table — main entry is `http://localhost:8081`.
   Added `TRAEFIK_HTTP_PORT` to key config variables.

6. **deploy/README.md**: Updated port listing from `80/443` to `8081/4433`.

## Prevention

- Never enable `forceSTSHeader` or HSTS headers in a dev stack that uses
  plain HTTP on port 80 — the browser cache lasts 1 year and cannot be
  cleared server-side.
- Dev stack should always use non-standard ports for HTTP to avoid browser
  HSTS interference. Use env vars (`TRAEFIK_HTTP_PORT`, `BACKEND_PORT`) to
  make ports configurable.
- Add a comment next to any `forceSTSHeader` usage warning about browser cache
  permanence.
- Add HSTS-related port mapping documentation whenever Traefik is reconfigured.
